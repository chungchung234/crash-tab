# 화면부수기 (Crash Screen)

보고 있는 웹페이지를 유리판으로 바꿔서 마음껏 깨뜨리는 크롬 확장 프로그램입니다.

클릭하면 포인터 위치에 유리 균열이 생기고, 화면이 번쩍이며 흔들리고, 합성된 타격음이 납니다.
그리고 **그 자리에 있던 실제 DOM 요소**가 조각나서 중력에 따라 떨어지고 화면 아래에 쌓입니다.
페이지를 스크린샷으로 찍어서 부수는 것이 아니라, 컴포넌트·텍스트 같은 요소 하나하나가 직접 반응합니다.
v1.2부터는 FPS처럼 **탄창과 재장전**, **저격총과 조준경(2배 확대)**, **숫자키 로드아웃**이 있고,
**큰 요소들이 플레이어(포인터)를 공격**하는 전투 모드가 켜져 있습니다. 모든 것은 새로고침 없이 **복구**할 수 있습니다.

## 기능

- 열 가지 무기: 🔨 망치 / 🔫 권총 / 💥 기관총 / 🎯 저격총 / 🪓 도끼 / 🗡️ 검 / 💣 폭탄 / 🚀 로켓 / 🔥 화염방사기 / 🌪️ 붕괴
- **크기 기반 체력(HP)**: 요소가 클수록 체력이 높습니다 (글자 요소는 최대 60 — 망치 한 방). 무기마다 피해량이 다르고
  공격력 배율(×0.5 ~ ×4)과 10% 치명타(×2)가 적용됩니다
- **탄창과 재장전**: 총기·폭발 무기는 탄창이 있고(예비 탄약 ∞), 비면 자동으로, `R`로 수동으로 재장전합니다. 무기 교체 딜레이 250ms
- **저격총과 조준경**: 마우스 오른쪽 버튼이나 `Shift`를 누르고 있으면 조준경이 켜지고 페이지가 **2배 확대**됩니다.
  무배율 사격은 ±25px 퍼지고, 조준 사격은 정확하며 헤드샷(치명타) 확률이 25%입니다
- **로드아웃**: 10개 무기를 `1`~`9`, `0` 키에 원하는 순서로 배치합니다. 프리셋 5종, `Shift+숫자`·드래그로 순서 변경, `Q`/`E`로 이전/다음
- **전투 모드**: 화면에 보이는 큰 요소가 적이 되어 크기에 따라 탄환·돌진·레이저로 플레이어를 공격합니다. 체력·점수·처치 수, KO 화면
- 맞을 때마다 **피해 숫자**가 떠오르고, 요소가 붉게 물들며, 호버 라벨의 **체력 바**가 줄어듭니다
- 아직 안 부서진 요소는 **흔들리거나 눌리는** 피해 반응을 보여줍니다
- 글이 많은 요소는 **단어·글자 단위로** 흩어져 떨어집니다
- 조각은 바닥·벽에 튕기고, 먼저 떨어진 조각 위에 **쌓입니다**
- 유리 균열은 화면에 **누적**되고, 복구할 때만 지워집니다
- HUD에서 무기 전환(2×5 그리드) / 로드아웃 프리셋 / 공격력 조절 / 소리 끄기 / 복구 / 전투 ON·OFF / 종료, 조각·균열·피해·점수·콤보 카운터,
  탄약 HUD(오른쪽 아래), 플레이어 HUD(왼쪽 아래), 토스트 알림
- 소리는 Web Audio로 합성 (오디오 파일 없음)
- 모든 UI 문자열 한국어 우선 (`_locales/ko`), 영어 대체 (`_locales/en`)

## 설치

1. 크롬에서 `chrome://extensions` 를 엽니다.
2. 우측 상단 **개발자 모드**를 켭니다.
3. **압축해제된 확장 프로그램을 로드합니다** 를 누르고 이 폴더를 선택합니다.
4. 아이콘은 `icons/`에 포함되어 있어 바로 툴바에 표시됩니다. (다시 생성하려면 `python3 tools/make-icons.py`를 실행하세요.)

빌드 과정이나 npm 의존성은 없습니다.

## 사용법

- 툴바의 화면부수기 아이콘을 클릭하거나 단축키 **Cmd+Shift+X** (Windows/Linux: **Ctrl+Shift+X**)를 누르면
  현재 탭이 "부수기 모드"가 됩니다. 다시 누르면 꺼집니다.
- 켜진 동안 페이지를 **클릭하면** 그 자리가 부서집니다 (기관총·화염방사기는 **꾹 누르고**, 검은 **드래그**해서 벱니다).
  페이지의 링크·버튼은 눌리지 않습니다 (휠 스크롤과 터치 스크롤은 그대로 됩니다).
- 마우스를 올리면 다음에 맞을 요소가 빨간 테두리로 표시되고, `IMG 67/127` 처럼 태그 이름과 **남은 체력/최대 체력**,
  그 아래 작은 체력 바(초록 → 노랑 → 빨강)가 보입니다.
- 켜지면 `⚔️ 전투 모드: 큰 요소들이 반격해요 (H로 끄기)` 토스트가 뜨고 5초 뒤부터 큰 요소들이 공격을 시작합니다.
  `H`로 끌 수 있습니다 (설정은 저장됩니다).

### 무기

키는 **기본 로드아웃** 기준입니다 (로드아웃 절 참고).

| 이름 | 키 | 피해 | 쿨다운 | 탄창 / 재장전 | 범위 | 조작 |
| --- | --- | --- | --- | --- | --- | --- |
| 🔨 망치 | `1` | 65 | 없음 | ∞ | – | 클릭 |
| 🔫 권총 | `2` | 25 | 없음 | 12발 / 900ms | – | 클릭 (작은 탄흔 + 유리 파편) |
| 💥 기관총 | `3` | 22/발 | – (70ms마다 자동 발사) | 30발 / 1400ms | – | **꾹 누르기** — 포인터를 따라 ±9px 흔들리며 연사 |
| 🎯 저격총 | `4` | 200 (헤드샷 400) | 600ms (볼트액션) | 5발 / 2000ms | – | 클릭 — 조준경은 **오른쪽 버튼 / Shift**, 무배율은 ±25px 퍼짐, 예광탄 |
| 🪓 도끼 | `5` | 130 | 550ms | ∞ | – | 클릭 — 묵직한 균열, 부서진 요소는 **세로 두 조각**으로 갈라집니다 |
| 🗡️ 검 | `6` | 요소당 60 | 없음 (찌르기 120ms) | ∞ | 선 | **드래그**해서 베기 (12px 미만이면 찌르기) — 선 위의 요소를 최대 12개까지, 부서진 요소는 **베인 선을 따라 두 조각** |
| 💣 폭탄 | `7` | 190 → 51 (가장자리) | 700ms | 3발 / 1800ms | 반경 240px | 클릭 — 최대 10개, 거리에 따라 피해 감소 |
| 🚀 로켓 | `8` | 260 → 70 (가장자리) | 1200ms | 2발 / 1500ms | 반경 360px | 클릭 — 화면 아래에서 150ms 날아와 폭발, 최대 14개, 큰 충격파 링 |
| 🔥 화염방사기 | `9` | 15/틱 | – (50ms마다) | 연료 100 (틱당 1) / 2500ms | – | **꾹 누르기** — 불꽃 입자, 유리가 서서히 그을리고, 부서진 조각은 **탄 색**이 됩니다 |
| 🌪️ 붕괴 | `0` | ∞ (체력 무시) | 2000ms | 1회 / 5000ms 충전 | 전체 | 클릭 — 클릭 지점에서 멀어지는 순서로 연쇄 붕괴 |

범위 무기의 피해는 `round(중심 피해 × (1 − 0.73 × t))` (`t` = 폭심에서 요소 가장자리까지 거리 ÷ 반경)로 줄어듭니다.
쿨다운 중의 클릭은 무시되지만(짧은 "딸깍" 소리와 HUD 버튼 테두리 깜빡임) 카운터·균열·피해는 바뀌지 않습니다.
꾹 누르는 무기는 `pointerup`, 창 포커스 이탈, `Esc`, 복구/종료, 10초 안전 제한, 탄창 소진 중 어느 것으로도 멈춥니다.

### 저격총과 조준경

- 저격총을 든 채 **마우스 오른쪽 버튼**을 누르고 있거나 **`Shift`** 를 120ms 이상 누르고 있으면 조준경이 켜집니다
  (놓으면 꺼집니다. `Shift+숫자`, `+`/`_` 같은 조합키는 조준경을 켜지 않습니다).
- 조준경: 포인터를 따라 움직이는 원(반지름 = 짧은 변의 42%) 바깥이 어두워지고, 십자선·밀도트·링이 그려지며 ±3px 흔들림이 있습니다.
  십자선은 적(전투 모드의 적대 요소) 위에서 빨갛게 변하고, 발사하면 40px 튀어 올랐다가 250ms 동안 되돌아옵니다.
- **2배 확대**: 조준경이 켜지는 순간 `document.body`에 `transform: scale(2)`를 적용합니다 (포인터 위치가 기준점이라 페이지가 흘러가지 않음).
  끌 때 원래 인라인 스타일을 그대로 되돌립니다. 유리층(균열·조각·HUD)은 확대되지 않습니다.
- **무배율 탄 퍼짐**: 조준하지 않은 사격은 x·y 각각 ±25px 안에서 랜덤하게 빗나갑니다. 조준 사격은 정확합니다.
- **헤드샷**: 치명타 확률이 조준 시 25%, 무배율 10% (피해 ×2, `헤드샷!` 표시).
- 볼트액션: 발사 후 600ms 동안 다시 쏠 수 없고 "철컥" 소리가 두 번 납니다. 발사 지점까지 화면 오른쪽 아래에서 **예광탄** 선이 그어집니다.
- 조준경은 무기 교체, 재장전 시작, 복구, 종료, `Esc`, 창 포커스 이탈, KO 화면에서 자동으로 꺼집니다.

### 탄약과 재장전

| 무기 | 탄창 | 재장전 |
| --- | --- | --- |
| 망치 · 도끼 · 검 | ∞ | – |
| 권총 | 12 | 900ms |
| 기관총 | 30 | 1400ms |
| 저격총 | 5 | 2000ms |
| 폭탄 | 3 | 1800ms |
| 로켓 | 2 | 1500ms |
| 화염방사기 | 연료 100 (틱당 1) | 2500ms (자동 재급유) |
| 붕괴 | 1회 충전 | 5000ms |

- 예비 탄약은 무한입니다. 마지막 탄을 쏘면 **자동 재장전**이 바로 시작되고, 재장전 중의 발사는 무시됩니다 (빈 탄창 "딸깍" 소리는 300ms에 한 번).
- `R`로 **수동 재장전** (탄창이 꽉 차 있거나 이미 재장전 중이면 무시). 재장전 중에 무기를 바꾸면 재장전이 취소되고 탄 수는 그대로입니다.
- **교체 딜레이**: 무기를 바꾸면 250ms 동안 쏠 수 없습니다 (탄약 HUD에 `교체 중`).
- **탄약 HUD** (오른쪽 아래): 무기 이모지, 큰 숫자 `12 / ∞`, 재장전 진행 바. 탄이 20% 이하면 숫자가 빨개지고, 비면 `R 재장전`이 깜빡입니다. 근접 무기는 `∞`.

### 로드아웃

- 로드아웃은 10개 무기 전체의 순서이며 `1 2 3 4 5 6 7 8 9 0` 키에 그대로 대응합니다 (10번 슬롯 = `0`).
- 프리셋 (HUD의 `로드아웃` 줄):
  - **기본**: 망치, 권총, 기관총, 저격총, 도끼, 검, 폭탄, 로켓, 화염방사기, 붕괴
  - **돌격**: 기관총, 권총, 저격총, 폭탄, 로켓, 화염방사기, 망치, 도끼, 검, 붕괴
  - **저격**: 저격총, 권총, 망치, 검, 도끼, 기관총, 폭탄, 로켓, 화염방사기, 붕괴
  - **폭발**: 로켓, 폭탄, 화염방사기, 붕괴, 기관총, 권총, 저격총, 망치, 도끼, 검
  - **근접**: 망치, 도끼, 검, 권총, 기관총, 저격총, 폭탄, 로켓, 화염방사기, 붕괴
- 순서 바꾸기: `Shift+숫자`는 **현재 무기**를 그 슬롯으로 옮기고(원래 그 자리에 있던 무기는 현재 무기의 자리로),
  HUD 그리드에서 무기 버튼을 다른 버튼 위로 **드래그**해도 두 슬롯이 바뀝니다. 둘 다 프리셋을 `사용자 지정`으로 바꿉니다.
- `Q` = 이전 슬롯, `E` = 다음 슬롯 (끝에서 반대쪽으로 넘어감).
- HUD 그리드는 2×5이며 각 버튼에 슬롯 키 배지와 이모지가 있고, 이름과 피해는 툴팁과 그리드 아래 한 줄(`🔨 망치 · 65`)에 보입니다.
- 로드아웃(`crsLoadout`)과 프리셋 이름(`crsLoadoutPreset`)은 `chrome.storage.sync`에 저장됩니다.

### 전투 모드

플레이어는 **포인터**입니다. 켜지고 5초가 지나면 1.5초마다 화면에 보이는 요소 가운데 면적 40 000px² 이상, 뷰포트의 70% 이하인 것을
(√면적 가중 랜덤으로) 하나 골라 적으로 만듭니다 (동시에 3개, 60초 뒤 5개). 적대 요소에는 빨간 테두리와 `👿 TAG` 라벨이 붙고
요소를 따라다닙니다. 공격 주기는 시간이 지날수록 짧아집니다 (2분에 걸쳐 최대 절반까지).

| 등급 | 면적 (px²) | 공격 | 주기 | 피해 |
| --- | --- | --- | --- | --- |
| T1 사수 | 40 000 ~ 150 000 | 중심에서 250ms 충전 후 플레이어 쪽으로 **탄환 구체** 발사 (520px/s, 최대 3초) | 1.8초 | 8 + round(√면적 / 60) |
| T2 돌진 | 150 000 ~ 400 000 | 700ms 경고(빠른 깜빡임 + 경고 링) 뒤 **슬램** — 요소 영역 + 60px 안에 있으면 피격, 충격파 링과 흔들림 | 3초 | 18 + round(√면적 / 50) |
| T3 레이저 | 400 000 ~ | 점선이 플레이어의 y(가로형) 또는 x(세로형)를 550ms **추적**하고, 250ms **고정**된 뒤 400ms **발사** — 선에서 16px 안이면 피격 + 흰 섬광 | 4.5초 | 30 |

- **탄환 구체는 쏠 수 있습니다**: 구체 중심 18px 안을 어떤 무기로든 때리면 구체가 터지고(+5점) 페이지는 맞지 않습니다.
  폭탄·로켓은 반경 안의 구체를 모두 터뜨리면서 페이지도 때리고, 검은 베는 선 18px 안의 구체를 터뜨립니다.
- **적대 요소는 한 몸**입니다: 적의 자식 요소를 때려도 적 자체가 맞습니다. 적을 부수면 **처치** — 라벨 `처치!`, 최대 체력만큼 점수
  (공격 준비 중에 부수면 ×1.5), 처치 수 +1. 전투 중에는 일반 요소를 부숴도 최대 체력의 1/4만큼 점수가 오릅니다.
- **플레이어 체력** 100. 맞으면 빨간 비네트, 화면 아래 플레이어 HUD 흔들림, 둔탁한 소리, 포인터 옆에 빨간 `-N`. 3초 동안 안 맞으면 초당 3씩 회복합니다.
- **플레이어 HUD** (왼쪽 아래, 전투 모드일 때만): `체력` 바(160×10px, 초록/노랑/빨강)와 숫자, `점수`, `처치`, `생존 N초`, `적 K`.
- **KO**: 체력이 0이 되면 `💀 당신은 부서졌습니다` 화면이 뜨고 (`점수 N · 처치 M · 생존 S초`) 공격·사격이 멈춥니다.
  `다시 시작 (Enter)` = 복구 + 플레이어 초기화 + 5초 유예, `종료 (Esc)` = 부수기 모드 종료.
- 창 포커스를 잃거나 탭이 숨겨지면 공격이 **일시정지**되고(날아가던 구체·레이저는 사라짐), 돌아오면 1초 뒤 재개됩니다.
  포인터가 창 밖에 있는 동안은 공격하지 않습니다. 화면 밖으로 2초 넘게 나간 적은 풀려납니다.
- **`H`** 또는 HUD의 `⚔️ 전투 ON/OFF` 버튼으로 끄고 켭니다 (`crsCombat`에 저장). 끄면 적 표시·구체·레이저가 사라지고 점수는 남습니다.
  복구하면 체력·점수·처치·생존 시간이 초기화되고 유예 5초가 다시 시작됩니다.

### 체력(HP)

처음 호버하거나 맞을 때 요소의 **화면상 크기**로 최대 체력이 정해지고, 복구할 때까지 유지됩니다 (조준경 확대 중에도 원래 크기 기준).

```
area  = 요소 rect 의 너비 × 높이 (CSS px)
base  = 20 + 0.35 × √area
종류   = 미디어 (img, picture, svg, video, canvas)                              → base × 1.2
      | 컨트롤 (button, input, select, textarea, [role=button], summary)       → base × 1.0
      | 글자 요소 (p, span, li, td, th, h1~h6, a, label, code, blockquote 등)   → base × 0.6, 최대 60
      | 그 외 컨테이너                                                         → base × 1.0
maxHp = 10 ~ 400 사이로 제한
```

예: 60×20 단어 `span` → 19, 120×40 버튼 → 44, 300×200 이미지 → 127, 580×380 카드 → 184, 1200×600 섹션 → 317,
긴 문단이나 `h1`은 60(상한), 그보다 큰 것은 400에서 포화합니다. 글자 요소는 상한이 60이라 **망치 한 방**에 흩어집니다.
망치 기준으로 단어/버튼/이미지/카드/섹션을 부수는 데 1/1/2/3/5번, 권총은 1/2/6/8/13번, 저격총은 184까지 한 방, 400은 두 방입니다.
붕괴는 체력을 무시합니다.

### 공격력 배율

HUD의 `공격력 ×1` 줄에서 `−`/`+` 버튼이나 `-`/`=` 키로 ×0.5 → ×1 → ×2 → ×4 를 고릅니다 (`chrome.storage.sync`의 `crsPower`에 저장).
붕괴를 제외한 모든 무기의 피해에 곱해집니다. 실제 피해는 `max(1, round(무기 피해 × 배율 × (치명타 ? 2 : 1)))` 입니다.

### 타격 피드백

- **피해 숫자**: 맞은 자리에서 `-65` 가 떠올라 사라집니다. 치명타(10%)는 `-130!` 이 금색으로 더 크게 뜹니다 (저격총은 `헤드샷! -400!`).
  기관총·화염방사기는 150ms 단위로 합산한 숫자를 하나씩 띄웁니다 (요소당 창마다 치명타를 한 번 굴립니다).
- **치명타**: 피해 ×2, 더 센 흔들림, 높은 타격음, 호버 라벨의 체력 바가 하얗게 번쩍입니다.
- **붉은 물듦**: 맞은 요소 영역이 타격 지점을 중심으로 붉게 물들었다가 180ms 안에 사라집니다 (꾹 누르는 동안은 옅게 유지).
- **체력 바**: 호버 라벨 아래 46×3px 바가 `hp/max` 비율만큼 차 있고, 60% 초과 초록, 30% 초과 노랑, 그 이하 빨강입니다.
- HUD 카운터 아래 고정된 한 줄에 마지막 타격이 `IMG -65 (62/127)` 처럼 1.2초 동안 표시됩니다 (치명타면 `치명타!`, 저격 헤드샷이면 `헤드샷!` 접두).
- **토스트** (화면 위 가운데): 전투 모드 켜짐/꺼짐, 프리셋 적용(`로드아웃: 돌격`), 슬롯 이동(`3 ← 🔨 망치`), 수동 재장전, KO.

### HUD 버튼과 단축키

| 버튼 | 키 | 동작 |

`클릭해서 발사 · 오른쪽 버튼이나 Shift로 조준해요` 로 바뀌고, 전투 모드에서는 `점수`도 표시됩니다.
HUD는 제목 줄을 끌어서 옮길 수 있습니다. 입력창에 포커스가 있을 때는 `Esc`만 동작합니다.

## 복구 / 종료

- **복구(Z)**: 떨어진 조각·균열·피해 숫자·불꽃·로켓·예광탄·적 표시·구체·레이저를 모두 지우고, 숨겼던 원래 요소의 인라인 스타일을 그대로 되돌립니다.
  체력과 발사·피해·치명타·그을림 카운터, 탄창, 플레이어 체력·점수·처치가 초기화되고, 진행 중인 꾹 누르기·베기·재장전·조준경은 취소됩니다.
  부수기 모드는 유지되고 전투 유예 5초가 다시 시작됩니다.
- **종료(Esc / 툴바 아이콘 / 단축키)**: 복구를 수행한 뒤 오버레이·HUD·이벤트 리스너·타이머를 전부 제거합니다.
  페이지에는 아무 흔적도 남지 않습니다 (`data-crs` 노드 0개, `body`의 transform 원상복구).
- 탭을 떠나거나(bfcache 포함) 새로고침하면 자동으로 꺼집니다. 툴바 배지 `ON`은 실제 상태에 맞춰 갱신됩니다.

## 요소와 직접 반응하는 기능

### 피해 반응

체력은 위 "체력(HP)" 절의 크기 공식으로 정해집니다 (`api.hpOf(el)` 로 읽을 수 있습니다).
체력이 남아 있으면 요소 **원본**이 맞은 방향으로 흔들리고(스프링), 폼 컨트롤은 눌리듯 찌그러집니다.
페이지가 이미 적용한 `transform` 위에 `composite: 'add'`로 겹쳐지므로 레이아웃은 바뀌지 않습니다.
꾹 누르는 무기는 흔들림·물듦·HUD 타격 줄을 요소당 150ms에 한 번만 갱신하고, 체력 라벨과 바는 매 틱 갱신합니다.

### 텍스트 흩뿌리기

텍스트 위주 요소(이미지·표·입력창을 포함하지 않고, 하위 요소 40개 이하, 80단어 이하)가 부서지면
`Range.getClientRects()`로 단어(또는 글자)의 실제 위치를 재서 **단어 하나하나가 따로** 떨어집니다.
`h1`~`h3`이거나 글자 수가 24자 이하이면 글자 단위, 아니면 단어 단위입니다 (이모지는 쪼개지 않습니다.
띄어쓰기 없는 긴 한글/한자 덩어리는 2~4자씩 나눕니다). 줄바꿈된 단어는 줄마다 한 조각이 됩니다.
배경이나 테두리가 있으면 상자가 글자를 투명하게 만든 조각 하나로 따로 떨어집니다.
충돌 지점에 가까운 단어일수록 더 빨리, 먼 단어는 아주 잠깐 늦게 출발합니다.

### 조각과 물리

- 요소는 계산된 스타일을 복사한 복제본으로 만든 뒤 `clip-path` 다각형으로 잘라서 조각냅니다
  (망치 4조각, 폭탄·로켓 6조각, 권총·기관총·저격총·화염 2조각, 이미지는 6~8조각; 도끼와 검은 글자를 흩뿌리지 않고 항상 **두 조각**).
  커스텀 엘리먼트는 생성자가 실행되지 않도록 `div`로 복제합니다.
- 중력 2400px/s², 바닥과 벽에서 튕기고, 먼저 멈춘 조각의 윗면 위에 쌓입니다. 멈춘 조각은 잔해로 남습니다.
- 살아 있는 조각은 최대 160개입니다. 넘치면 오래된(멈춘) 조각부터 흐려지며 사라지고, 그 위에 있던 조각은 다시 떨어집니다.
- 모든 조각은 `position: fixed` 유리층(`.crs-root`) 안에 있으며 스크롤의 영향을 받지 않습니다. 조준경 확대 중에 부서진 조각은 2배 크기로 남습니다.

### 호버 하이라이트

포인터가 올라간 요소에 빨간 테두리와 `DIV 119/184` 같은 라벨(태그 이름 + 남은 체력/최대 체력), 그 아래 체력 바가 붙습니다.
맞을 때마다 테두리가 번쩍이고 라벨과 바가 즉시 갱신됩니다.

### 붕괴

`document.body`부터 너비 우선으로 훑어 화면 안에 보이는 요소(뷰포트의 25% 이하 크기)를 최대 60개 모아
클릭 지점에서 가까운 순서로 약 1.1px/ms 속도의 파동처럼 차례로 무너뜨립니다. 가까운 텍스트 요소 8개까지는 단어 단위로 흩어집니다.
낮은 울림 소리와 함께 망치 타격음이 반복되고, 끝나면 HUD에 `복구(Z)로 되돌릴 수 있어요`가 표시됩니다. 같은 너비 우선 탐색이 전투 모드의
적 후보(40 000px² 이상, 뷰포트 70% 이하, 큰 섹션 안의 카드도 포함)를 고르는 데 쓰입니다.

### 폼 필드와 미디어

- `input` / `textarea` / `select` 복제본에는 현재 값·체크 상태·선택 항목이 복사됩니다.
  글자가 들어 있는 텍스트 필드는 부서질 때 그 글자도 단어 조각으로 쏟아집니다 (최대 40개).
- `video`는 부서질 때 일시정지됩니다. 복구해도 **자동으로 다시 재생하지 않습니다**. `audio`는 건드리지 않습니다.
- `canvas` / `video`는 현재 프레임을 새 캔버스에 그려서 조각으로 씁니다.

## 제한사항

- `chrome://`, `chrome-extension://`, `about:`, 크롬 웹스토어, 내장 PDF 뷰어 등 확장 프로그램이 스크립트를 넣을 수 없는
  페이지에서는 동작하지 않습니다 (툴바 배지에 `✕`가 잠깐 표시됩니다).
- `iframe` / `object` / `embed` 는 내부를 복제할 수 없어 **통째로 한 블록**으로 부서집니다. 교차 출처 iframe도 마찬가지입니다.
- SPA 프레임워크가 인라인 스타일을 다시 렌더링하면 숨겨 둔 원본이 다시 보일 수 있습니다 (5번까지 자동으로 다시 숨기고,
  그래도 안 되면 **복구** 후 다시 부수세요).
- WebGL 캔버스는 (`preserveDrawingBuffer`가 아니면) 밋밋한 블록으로 보일 수 있습니다.
- modal `<dialog>`가 열려 있으면 그 바깥은 비활성(inert)이라 대화상자 안의 내용만 부술 수 있습니다.
- 페이지가 `window`의 캡처 단계에 등록한 키보드 핸들러는 우리 단축키보다 먼저 실행될 수 있습니다.
- 내부 스크롤 영역(`overflow: auto`) 위에서 휠을 굴리면 휠 이벤트를 전달해 그 영역이 스크롤됩니다.
  바깥에서는 문서가 평소처럼 스크롤됩니다.
- 요소가 `visibility: hidden`으로 숨겨지므로 레이아웃은 그대로입니다 (조각이 떨어져도 페이지가 재배치되지 않습니다).
- 글자 클립 등으로 가려진 텍스트(보이는 면적 50% 미만)는 조각으로 만들지 않습니다.
- 터치 화면에서 기관총·화염방사기를 누른 채 손가락을 움직이면 브라우저의 스크롤 제스처(`pointercancel`)가 끼어들어
  연사가 멈춥니다 (의도된 동작 — 제자리에서 꾹 누르세요). 검 베기도 마찬가지로 손가락을 떼는 지점까지만 적용됩니다.
- **조준경 확대**는 `body`에 이미 `transform`이 있는 페이지, `html { zoom }`을 쓰는 페이지, 시스템의 "움직임 줄이기" 설정에서는
  건너뜁니다 (조준경 화면만 표시). 확대 중에는 페이지의 `position: fixed` 요소가 `body` 기준으로 다시 배치되고,
  확대된 `body`만큼 스크롤 영역이 늘어나 스크롤바가 보일 수 있습니다.
- **전투 모드**는 창이 포커스를 잃거나 탭이 숨겨지면 일시정지되고, 포인터가 창 밖에 있는 동안은 공격하지 않습니다.

## 개발 / 테스트

```bash
python3 tools/make-icons.py   # icons/icon{16,32,48,128}.png 생성 (순수 파이썬, Pillow 불필요)
node test/e2e.js              # headless puppeteer e2e (test/out/ 에 스크린샷)
CRS_SEED=1234 node test/e2e.js  # 스트레스 테스트의 클릭 좌표 시드 (실패한 실행을 로그의 시드로 재현)
node --check background.js && node --check content.js && node --check test/e2e.js   # --check 는 첫 번째 파일만 검사하므로 파일마다 실행

```

e2e는 세 가지를 검사합니다: (A) 콘텐츠 스크립트 하네스, (B) 엄격한 CSP + Trusted Types 페이지, (C) 실제 확장 프로그램
로딩(백그라운드 서비스 워커를 통한 토글, 배지, 포인터 이벤트).

페이지 콘솔에서 `window.__crashScreen` 으로 디버그할 수 있습니다: `setWeapon(id)` / `weapon`, `setPower(v)` / `power`,
`weapons()` (로드아웃 순서, `slot`/`key`/`mag`/`reloadMs`/`spread`/`scope` 포함), `hpOf(el)`, `smashAt(x, y, weaponId?)`,
`slash(x1, y1, x2, y2)`, `ammo()` / `reload()`, `loadout()` / `setLoadout(ids)` / `applyPreset(name)`, `scope(on)`,
`player()`, `setCombat(bool)` / `combat`, `restore()`, `stats()` (`shots`, `damageDealt`, `crits`, `scorch`, `holding`,
`mag`, `reloading`, `swapping`, `scoped`, `magnified`, `lastShot`, `combat`, `hostiles`, `orbs`, `playerHp`, `score`, `kills`, `paused` …),
그리고 테스트용 플래그 `debug = { noCrit, forceCrit, noCooldown, noSpread, noAttacks, fastReload, infiniteAmmo }` 와
훅 `debug.setPlayerHp(n)` / `debug.setPlayerPos(x, y)` / `debug.forceAttack(el)`. `setMode('gun')` 은 v1 호환 별칭으로 `pistol` 을 고릅니다.

## 파일 구조

```
manifest.json              MV3 매니페스트 (activeTab, scripting, storage)
background.js              서비스 워커: 토글, CSS/JS 주입, 배지
content.js                 핵심: 입력 가로채기, 타겟 선택, 체력/무기/피해, 탄약·조준경·로드아웃·전투 모드, 조각 물리, 균열 캔버스, 소리, HUD
content.css                문서 레벨 스타일 (crs- 접두사만 사용, USER origin 으로 주입)
icons/                     icon16/32/48/128.png (tools/make-icons.py 가 생성)
_locales/ko, _locales/en   UI 문자열
tools/make-icons.py        아이콘 생성기
test/e2e.js                puppeteer e2e
test/fixture.html/.css/.js e2e용 데모 페이지
```

## 권한 설명

| 권한 | 용도 |
| --- | --- |
| `activeTab` | 툴바 아이콘을 누른 **그 탭에만** 스크립트를 넣기 위해. 모든 사이트 접근 권한(`host_permissions`)은 요구하지 않습니다 |
| `scripting` | `chrome.scripting.insertCSS` / `executeScript` 로 `content.css`, `content.js` 를 주입 |
| `storage` | 선택한 무기(`crsWeapon`), 공격력 배율(`crsPower`), 음소거 여부(`crsMuted`), 로드아웃(`crsLoadout`, `crsLoadoutPreset`), 전투 모드(`crsCombat`)를 `chrome.storage.sync` 에 저장 (v1의 `crsMode` 값은 읽어서 변환: `gun` → `pistol`) |

네트워크 요청, 외부 리소스, 데이터 수집은 전혀 없습니다. 페이지 CSP(Trusted Types 포함)를 우회하지 않도록
`innerHTML`·`eval`·인라인 `style` 속성을 쓰지 않고 DOM API와 CSSOM만 사용합니다.
