# 로드맵

사용자 피드백에서 나온 남은 작업을 의존 순서대로 정리한다.
각 단계는 전체 테스트를 통과시키고 커밋해 푸시한 뒤 다음으로 넘어간다.
상세 명세는 세션 스크래치패드의 `SPEC-*.md` 에 있고, 여기에는 무엇을·왜·어떤 순서로만 적는다.

## 단계

### 1. 모델 교정 — 화면이 아니라 요소를 부순다 (최우선)

지금은 뷰포트에 고정된 캔버스에 균열을 그린다. 화면 앞 유리판을 깨는 모델이라
**스크린을 부순 것처럼** 보이고, 스크롤하면 자국이 화면에 붙어 따라온다.

- 전체 화면 캔버스를 없애고 **요소별 데칼**에만 자국을 그린다. 요소 경계에서 잘린다.
- 조각을 문서에 고정한다(기본값 전환). 떨어진 자리에 남는다.
- **재질 5종**: 패널 · 종이 · 유리 · 플라스틱 · 금속. 유리 균열은 이미지와 비디오에만 쓴다.
- 화면에 남는 것은 섬광·충격파·흔들림·비네트뿐이고 전부 일시적이다.

### 2. 설정 체계 · 성능 가드 · 접근성

뒤의 단계 대부분이 설정 키를 추가한다. 먼저 받침을 만든다.

- `settings-schema.json` 단일 소스, 저장·구독·마이그레이션
- 성능 모드 자동 전환(요소 수·프레임 비용 측정), 후보 탐색 캐시
- 모션 축소 전면 적용, 고대비 표식, 키보드 조작, 스크린 리더 안내

### 3. 전투 재구성

- **아케이드 모드**: 버추어 캅을 폐기하고 **커서가 곧 캐릭터**인 모드로 교체.
  조작만 다르고 실패 조건은 서바이벌과 동일. 한 손 조작이므로 난이도 보정을 받는다.
- **전투 중에는 적만 부서진다.** 나머지는 무적. 무적 타격은 튕김 표시와 금속음으로 알린다.
  상태 효과(불·젖음·빙결·변위)는 무적 요소에도 붙어 간접 공격 수단이 된다.
- **변위 시스템**: 요소를 부수지 않고 미는 상태. 질량·마찰·충돌 피해. 뒤의 돌격과 상호작용 무기가 이걸 쓴다.
- **투사체 4종**: 직사 · 유도 · 산탄 · 포물선. 전부 요격 가능.
- **요소 종류가 공격을 정한다**: 이미지는 포격, 테이블은 행 단위 연발, 버튼은 빠른 3연사,
  링크는 자신이 달려드는 돌격, 폼은 잠깐 따라오는 유도탄, 내비는 락온, 푸터는 지원.

### 4. 조준점 고도화 · 시각 정돈 · 뷰모델 위치

- 운영체제 커서를 끄고 직접 그린다. **산포가 조준점 간격에 그대로 보인다.**
- 무기별 모양, 히트마커, 준비 상태 링, 관통 힌트.
- **외곽선을 줄인다.** 호버 타겟은 모서리 괄호만, 적대 요소는 평상시 조용하고 공격 준비 때만 실선.
  체력 표시를 조준점 아래 바 하나로 옮기고 **길이가 최대 체력을 나타낸다.**
- 뷰모델이 구석에 눌려 안 보인다. 뷰포트 비례로 키우고 안쪽으로 들인다.

### 5. 무기 아트 재작업 · 카타나 교체

- 평면 실루엣을 재질 3단·접합부 음영·원통 그라데이션으로 다시 그린다. 해상도 2단(상세/아이콘).
- **망치와 도끼 재설계**: 망치는 갈라진 발톱이 없고, 도끼는 날이 180도로 펼쳐진 부채다.
- **검을 카타나로 교체**: 휜 외날, 하몬, 츠바. 베기 연출도 곡선 궤적과 뒤늦은 분리로 다시 만든다.

### 6. 무기별 파괴 효과 · 폭발 교정 · 연소

- 무기마다 분해 방식을 다르게: 쐐기·띠·반쪽·파편·재·덩어리.
- **타격 지점에 따라 다르게 부서진다.** 모서리를 치면 모서리만 떨어지는 부분 파괴.
- **폭발 교정**: 그을음 90px, 균열 420px, 링 480px, 실제 반경 240px이 전부 따로 논다.
  모든 크기를 실제 폭발 반경에 묶고, 거미줄 균열 대신 그을음과 분출 줄기를 남긴다.
- **연소 시스템**: 지속 피해와 확산. 맞닿은 요소로 번지고, 젖음·빙결과 상호작용한다.

### 7. 보조 공격 · 무기고 확장

- **길게 누르면 모으고 떼면 나간다.** 무기마다 다른 보조 공격.
- 레이저 커터(열 관리, 절단선 직접 그리기)와 미니건(예열) 추가.
- 로드아웃이 **무기고에서 10개를 고르는 방식**으로 바뀐다.

### 8. 상호작용 무기 · 예능 무기

- 충격포(민다) · 견인 광선(당긴다) · 고무탄(튕긴다)
- 뿅망치 · 물총 · 나팔 · 고무 치킨. 약하되 고유 효과가 있어야 한다.

### 9. 무기 다양화 · 밸런스 조정

- 샷건 · 못총(조각 고정) · 냉각총(피해 증폭) · 중력탄(끌어모으기)
- `tools/balance.js` 로 실효 화력과 처치 시간을 계산해 **밸런스를 테스트로 만든다.**
  CI 가 검사하므로 밸런스 회귀가 잡힌다.

### 10. 게임 시스템과 제품화

- 옵션 페이지(무기고 편집기, 무기 비교표, 통계)
- 누적 통계 · 챌린지 모드 · 보스전 · 무기 해금
- 인스펙터 모드 · 결과 공유 · 리플레이 · 사용자 정의 무기

## 병렬 가능

5단계(무기 아트)는 다른 단계와 의존이 없어 언제든 병렬로 돌릴 수 있다.
나머지는 위 순서를 따른다. 특히 1단계는 뒤의 모든 연출이 올라앉는 토대다.
