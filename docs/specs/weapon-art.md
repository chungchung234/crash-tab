# 무기 아트 재작업 · 카타나 교체

로드맵 5단계. 다른 단계와 의존이 없다.

사용자 피드백: "무기 이미지들도 현실적으로 교체하고 싶어 단순 이모지로는 부족해",
그리고 대조 시트를 보고 "도끼와 망치 디자인이 이상해".

현행 무기 그림은 그라데이션도 음영도 없는 평면 실루엣이다. 알아볼 수는 있지만 색칠한 도형으로
보인다. 망치는 발톱 없는 해머 블록이고, 도끼는 날이 거의 180도로 펼쳐진 흰 부채다.

## 0. 제약

- 이미지를 내려받거나 생성할 수 없고 기존 게임 아트는 저작권 문제가 있다.
- 따라서 **층을 쌓은 고밀도 SVG** 로 간다. 사진 같지는 않지만 이모지와는 범주가 다르다.
- 사용자가 PNG 를 주면 `icons/weapons/<id>.png` 를 우선 쓰는 경로를 열어둔다(§5).

## 1. 아트 디렉션 (공통)

이게 지켜져야 한 세트로 보인다. 하나라도 어긋나면 그 무기만 붕 뜬다.

- **광원 고정**: 좌상단 45도. 하이라이트는 좌상단 면, 음영은 우하단 면.
- **시점**: 뷰모델용은 오른쪽 아래에서 왼쪽 위를 향하는 3/4 시점. 정측면은 스티커처럼 보인다.
- **재질 3단**: 금속 `#d4dae4` / `#8e97a6` / `#3f4654`. 목재 `#a9794e` / `#8b6240` / `#5a3f28`.
  고무·폴리머 `#4a4f58` / `#33373e` / `#1e2127`. 강조 `#e5484d`, 황동 `#c8a24a`.
- **접합부 음영**: 부품이 만나는 선마다 2~3px 어두운 그라데이션. 이것만 넣어도 입체가 된다.
- **림 라이트**: 윗면 모서리를 따라 1px `rgba(255,255,255,.55)`.
- **원통 표현**: 총열·연료통·발사관은 길이 방향 3스톱 그라데이션. 단색 사각형 금지.
- **디테일은 3~5개만**. 더 넣으면 24px 에서 뭉갠다.
- **외곽선 없음**. 윤곽은 명도 차이로만. 선을 두르면 즉시 이모지처럼 보인다.

## 2. 해상도 2단 (LOD)

| LOD | 쓰는 곳 | 뷰박스 | 요소 수 |
|---|---|---|---|
| `detail` | 뷰모델 200px+ | `0 0 240 140` | 25~45 |
| `icon` | HUD 버튼 24px, 탄약 패널 28px | `0 0 48 48` | 6~12 |

`weaponArt(id, size, lod)` — `lod` 생략 시 `size >= 64` 면 `detail`.
`icon` 은 축소가 아니라 **따로 그린 단순화 버전**이다.

## 3. 무기별 실물 기준

| 무기 | 기준 | 필수 특징 |
|---|---|---|
| 망치 | 장도리 | 타격면, **갈라진 발톱**, 자루 테이퍼, 금속 칼라 |
| 권총 | 세미오토 | 슬라이드/프레임 분리선, 기운 그립, 방아쇠울, 가늠쇠 |
| 기관총 | 기관단총 | 수직 탄창, 총열덮개, 접이식 개머리판 |
| 저격총 | 볼트액션 | 긴 총열, 조준경 원통, 볼트 손잡이, 개머리판 치크 |
| 도끼 | 소방도끼 | **좁은 호의 날**, 테이퍼 몸통, **뒤쪽 픽**, 칼라 |
| 카타나 | 일본도 | **휜 외날**, **하몬**, 츠바, 마름모 감기 츠카 |
| 폭탄 | 파인애플 수류탄 | 격자 홈, 안전 레버, 핀 고리 |
| 로켓 | 어깨걸이 발사관 | 발사관, 배기 나팔, 광학 조준기, 앞 손잡이 |
| 화염방사기 | 배낭형 | 연료통 2개, 주름 호스, 점화구 노즐 |
| 붕괴 | T자 기폭기 | 나무 상자, T자 플런저, 전선 단자 |

## 4. 제작 절차 — 눈으로 보고 고친다

코드만 쓰고 끝내면 반드시 실패한다. **렌더해서 보는 루프를 먼저 만든다.**
무기마다 최소 3회 돈다.

1. SVG 를 만든다.
2. 헤드리스로 `detail` 200px 과 `icon` 24px 을 400% 확대한 것 두 장을 렌더한다.
3. 그 이미지를 직접 읽고 자문한다. 이름을 모르는 사람이 맞힐 수 있는가. 입체로 보이는가.
   24px 에서 다른 것들과 구별되는가.
4. 안 되면 고친다.

마지막에 `test/out/weapons.png` 와 `weapons-icon.png` 를 만들어 세트로서 어울리는지 본다.
근접 3종(망치·도끼·카타나)이 가장 헷갈리므로 이 셋을 특히 본다.

## 5. 사용자 제공 아트

`icons/weapons/<id>.png` (256×256, 투명 배경)가 있으면 `weaponArt` 가 `<img>` 를 돌려준다.
없으면 조용히 SVG 로 되돌아간다. 설정 `weaponArt: 'auto' | 'svg' | 'emoji'`, 기본 `auto`.
`tools/validate.js` 가 존재와 크기를 확인하고 `tools/package.js` 가 포함한다.

## 6. 스토어 심사

사실적인 총기 묘사는 설명을 요구받을 수 있다. 스토어 설명에 웹페이지 요소를 부수는 패러디
게임임을 명시하고, 사람이나 실존 대상을 겨누는 묘사를 넣지 않는다. 뷰모델 총구는 항상
화면 안쪽(페이지 쪽)을 향한다.

# 7. 망치와 도끼 재설계

## 7.1 공통 — 근접 도구의 비례

**머리가 너무 크다.** 둘 다 머리가 전체의 40% 이상이라 장난감처럼 보인다.

- 전체 길이 대비 **자루 62~68%**, 머리 32~38%.
- 자루 두께는 머리 높이의 18~22%.
- 자루는 끝으로 갈수록 2~3% 굵어지고 끝에 손잡이 마감이 있어야 한다.
- 머리와 자루가 만나는 곳에 **금속 칼라**. 자루를 감싸는 고리지 사이에 낀 쐐기가 아니다.

## 7.2 망치 — 장도리

현행은 사각 블록 머리의 해머다. **장도리의 갈라진 발톱이 없다.**

1. **타격면** — 살짝 볼록한 원통 단면. 폭은 머리 높이의 55%.
2. **목** — 타격면에서 뒤로 좁아지는 구간, 머리 길이의 30%.
3. **발톱** — 식별 포인트다. 뒤쪽에서 아래로 휘는 두 갈래.
   - 바깥 윤곽은 반지름이 머리 높이의 약 0.8배인 호.
   - 두 갈래 사이 V 홈은 발톱 길이의 **60%** 까지 파고들고 끝이 뾰족하다. 60% 가 하한이다.
   - 갈래 하나의 두께는 머리 높이의 12%.
4. **눈** — 자루를 감싸는 사다리꼴 칼라.
5. 자루는 목재, 끝 15% 는 어두운 고무 그립.

`icon` LOD: 타격면 + 발톱 V + 자루. **발톱 V 를 반드시 남긴다.**

## 7.3 도끼 — 소방도끼

현행은 날이 150도를 넘게 펼쳐진 흰 부채다.

1. **날** — 바깥 호의 중심각 **45~60도**. 반지름은 머리 높이의 1.1배. 날 끝에 1~2px 밝은 선.
2. **몸통** — 날에서 눈 쪽으로 좁아진다. 날 쪽 : 눈 쪽 = 1 : 0.45. 이 테이퍼가 도끼를 만든다.
3. **픽** — 반대쪽의 뾰족한 갈고리. 길이는 머리 높이의 0.55배, 끝으로 가늘어지고 아래로 휜다.
   실루엣을 비대칭으로 만들어 작은 크기에서도 도끼로 읽히게 하는 핵심이다.
4. **눈과 칼라**.
5. 자루는 목재에 붉은 고무 그립. 망치보다 20% 길다.

`icon` LOD: 45도 날 + 테이퍼 몸통 + 픽 + 자루. **픽을 반드시 남긴다.**

# 8. 검 → 카타나

## 8.1 이름

- 식별자 `sword` → **`katana`**. 저장된 `crsLoadout`/`crsWeapon` 의 `sword` 는 읽을 때 치환한다.
  프리셋 정의도 함께 바꾼다.
- 로케일 `weaponSword` → `weaponKatana`. 한국어 **카타나**, 영어 **Katana**.

## 8.2 그림

실물 기준 일본도, 3/4 시점.

- **휜 날** — 등이 완만한 호. 곡률은 날 길이의 약 1/22. 직선이면 카타나로 안 보인다.
- **외날** — 아래쪽만 날이고 등은 두껍다. 날 쪽에 밝은 하이라이트 띠.
- **하몬** — 날과 몸통 사이의 불규칙한 물결 경계. 밝은 띠 `rgba(255,255,255,.35)` 를
  10~14개의 완만한 호로 잇는다. **카타나임을 가장 강하게 말하는 요소다.**
- **츠바** — 작고 둥근 원반. 타원 + 중앙 구멍.
- **츠카** — 마름모 격자 감기. 교차 사선 8~10개.
- **카시라** — 손잡이 끝 금속 마감.
- 색: 날 `#e8edf5` / `#b9c2d0` / `#6d7788`, 츠바와 금구 황동, 츠카 감기 `#2b2f36`.

`icon` LOD: 휜 날 + 츠바 + 손잡이 3요소. 하몬과 격자는 생략하되 **곡률은 유지**한다.

## 8.3 이 단계에서 하지 않는 것

베기 연출(곡선 궤적·뒤늦은 분리·칼자국), 발도 보조 공격, 스탯 변경, 조준점 모양은
뒤 단계에서 한다. 절단 기하를 건드리면 다른 작업과 충돌한다.

# 9. 테스트

1. `weaponArt(id, 200)` 이 `detail`, `weaponArt(id, 24)` 가 `icon` 을 돌려준다
   (요소 수: detail ≥ 25, icon ≤ 12).
2. 모든 `detail` SVG 가 그라데이션을 2개 이상 쓴다.
3. 전체 윤곽선 stroke 가 없다(bounding box 가 전체의 90% 를 넘는 stroke 요소 없음).
4. 10종의 path 데이터가 서로 다르고 공통 팔레트 상수만 쓴다.
5. `icons/weapons/pistol.png` 를 넣으면 `<img>` 를, 지우면 `<svg>` 를 돌려준다.
6. `weaponArt: 'emoji'` 에서 이모지로 되돌아간다.
7. 전부 `createElementNS` 로 만들어지고 `innerHTML` 이 없다.
8. 망치 `detail` 에 발톱 path 가 있고 V 홈 깊이가 발톱 길이의 55% 이상이다.
9. 도끼 날 바깥 호의 중심각이 45~60도다.
10. 도끼 몸통의 눈 쪽 높이가 날 쪽의 0.5배 이하다.
11. 도끼 픽 path 가 있고 길이가 머리 높이의 0.45배 이상이다.
12. 두 무기 모두 자루가 전체 길이의 60% 이상이다.
13. `icon` LOD 에서도 발톱 V 와 픽이 각각 남아 있다.
14. `api.weapons()` 에 `katana` 가 있고 `sword` 는 없다. 저장된 `sword` 가 치환된다.
15. 로케일 양쪽에 `weaponKatana` 가 있고 `weaponSword` 는 없다.
16. 카타나 `detail` 에 하몬 호가 10개 이상 있고 등 곡선의 중점 편차가 0 이 아니다.
17. 대조 시트 2장이 생성된다.
