# 보조 공격 · 무기고 확장 · 상호작용 무기 · 예능 무기 · 밸런스

로드맵 7~9단계. 4단계(조준점의 준비 링)와 3단계(변위 시스템)가 재료로 필요하다.

---

# A. 보조 공격 (7단계)

사용자: "무기별로 필요하다면 마우스를 길게눌러 다른 느낌의 공격이나 휘두른다거나"

## A1. 문법 하나로 통일

지금은 무기마다 누르는 의미가 다르다. 망치는 클릭, 기관총은 길게, 카타나는 드래그. 배울 게 없다.

**길게 누르면 모으고, 떼면 나간다.** 이미 길게 누르기를 지속 발사에 쓰는 기관총·화염방사기만
반대로 **짧게 누르면 절제된 공격**이 나간다.

안전 규칙 셋:
- **120ms 미만으로 떼면 평소의 일반 공격.** 실수로 길게 눌러도 손해가 없다.
- 최대 충전 이후에는 좋아지지 않는다. 다 모이면 조준점이 번쩍이고 소리로 알린다.
- 충전 중에도 이동·조준·무기 교체가 된다. 교체하면 취소되고 탄약도 환불된다.

## A2. 무기별

| 무기 | 짧게 | 길게 | 유형 |
|---|---|---|---|
| 망치 | 한 방 65 | **내려치기** 0.6초 → 피해 ×2.2, 반경 120px 범위 | charge |
| 권총 | 반자동 25 | **정조준** 0.35초 → 산포 0, 피해 ×1.4 | steady |
| 기관총 | **3점사**(산포 ×0.5) | 지속 연사 | burst |
| 저격총 | 볼트액션 200 | **호흡 정지**(조준 중) → 흔들림 0, 치명타 40%, 2초 제한 | steady |
| 도끼 | 내려찍기 130 | **회전 베기** 0.8초 → 반경 160px 전부를 2조각으로, ×1.6 | charge |
| 카타나 | 드래그 베기 60 | **발도** 0.6초 → 화면 가로 전체 수평 호, 최대 16개, ×1.8, 관통 2 | charge |
| 폭탄 | 설치 190 / R240 | **심지 조절** 0.9초 → 반경 160→340 | charge |
| 로켓 | 직사 260 | **유도 조준** 0.7초 → 지정한 요소로 휘어 날아감 | lock |
| 화염방사기 | **화염탄**(불바다) | 지속 분사 | burst |
| 붕괴 | 전체 연쇄 | **범위 지정** 드래그한 사각형 안만 | marquee |

설계 의도: 근접·폭발은 모아서 크게 한 방, 총기는 기다리면 정확해진다. 로켓의 유도는 엄폐 뒤의
적을 치는 또 하나의 수단이 된다. 카타나의 발도는 찌르기보다 카타나답고 장면이 산다.

## A3. 충전 피드백

조준점 준비 링을 재사용하되 색이 다르다(`#8ab4ff`).
- 링이 0→1 로 차고, 다 차면 1프레임 흰색 번쩍 + 링이 2px 굵어진다.
- 조준점 팔이 안쪽으로 모인다(`gap` 최대 40% 축소). 집중되는 느낌.
- 뷰모델이 뒤로 당겨지거나 위로 들린다. 최대에서 미세하게 떨린다.
- 음정이 올라가는 톤(사인 180→420Hz), 최대에서 짧은 클릭.
- 범위형은 타격 반경 원이 충전과 함께 커진다. 유도는 지정 요소에 괄호가 붙는다.
  범위 지정은 사각형이 점선으로 그려지고 포함된 요소 수가 표시된다.

모션 축소 시 뷰모델 떨림과 번쩍임을 빼고 링과 색 변화만 남긴다.

## A4. 자원

보조 공격은 **탄약 2발**을 쓴다. 남은 탄이 모자라면 충전이 시작되지 않고 빈 클릭 소리가 난다.
근접 무기는 탄약이 없으므로 **쿨다운 ×1.8**. 3점사는 3발, 화염탄은 연료 12.
공짜로 더 센 공격을 주면 기본 공격을 쓸 이유가 없어진다.

## A5. 입력

기존 `startHold`/`holdStep`/`onHoldEnd` 와 포인터 캡처 위에 얹는다.
`pointerup` 시 눌린 시간으로 분기한다. `charge` 유형만 중간값을 보간하고,
`steady`/`lock` 은 완충이 아니면 일반 공격으로 떨어진다. 어중간한 정조준은 의미가 없다.
중단 조건(전부 취소 + 환불): `pointercancel`, `lostpointercapture`, `blur`,
`visibilitychange`, `Escape`, 무기 교체, 재장전 시작, KO.
카타나는 드래그 12px 이상이면 발도가 취소되고 평소 베기가 된다. 붕괴도 같은 기준으로 갈린다.

# B. 무기고 확장 (7단계)

## B1. 로드아웃 구조 변경

무기가 10종을 넘으면 숫자키 10칸을 넘는다.

- **무기고(arsenal)**: 존재하는 모든 무기.
- **로드아웃**: 무기고에서 고른 **최대 10개의 순서 있는 목록**. 숫자키에 매핑된다.
- `api.arsenal()` / `api.loadout()` / `api.setLoadout(ids)` — 부분집합, 중복 없음, 길이 1~10.
- 로드아웃에 없는 무기는 숫자키로 선택되지 않는다. `Q`/`E` 도 로드아웃 안에서만 순환한다.
- 프리셋이 **서로 다른 10개 조합**이 되어 실제 선택이 생긴다.

## B2. 레이저 커터

| 항목 | 값 |
|---|---|
| 기본 | 길게 눌러 **지속 빔**, 틱당 11 / 50ms (초당 220) |
| 보조 | 짧게 눌러 **단발 펄스** 90, 즉발 |
| 자원 | 탄창 없음. **열** 0~100, 틱당 +2.2, 펄스 +25 |
| 과열 | 100 에서 끊기고 **2.5초 강제 냉각** |
| 냉각 | 정지 0.4초 뒤 초당 28 |
| 관통 | **무제한**, 층마다 ×0.75 |
| 넉백 | 0.4 — 충격이 아니라 절단이라 흘러내린다 |
| 교체 / 이동 | 320ms / 0.88 |

전략은 "2초 쏘고 1.5초 식히기". 끊어 쏘면 과열하지 않는다. 이 리듬이 손맛이다.

**절단선**: 다른 무기는 "어디를 맞히는가"지만 레이저는 **"어디를 따라 지나가는가"** 다.
충돌 지점의 궤적을 기록해(최대 60점) 절단선을 그린다. 갓 지난 부분은 흰 고열, 뒤로 갈수록
주황 → 검은 흉터로 0.6초에 걸쳐 식는다. **누적 절단선이 요소를 가로지르면 그 궤적을 따라
나뉜다.** 지그재그로 끌면 지그재그로 잘린다.

빔: 중심 3px 흰색, 바깥 9px 글로우 **마젠타 `#ff4d9d`**(붉은색은 적대, 청록은 복구 빔이 쓴다).
열이 오를수록 글로우가 주황 → 흰색으로 이동하고 과열 직전엔 떨린다. 열 게이지를 안 봐도 안다.
`div` 를 회전·신축해 그린다. 캔버스가 아니다.

HUD: 탄약 패널이 **열 게이지**로 바뀐다. 조준점 준비 링이 열 게이지로 동작한다.

## B3. 미니건

| | 기관총 | 미니건 |
|---|---|---|
| 발사 시작 | 즉발 | **0.8초 예열** |
| 초당 피해 | 314 | **433** |
| 탄착군 확산 | 6/발 | **14/발** |
| 이동 속도 | 0.95 | **0.55 — 최저** |
| 교체 | 260ms | **560ms — 최장** |
| 탄창 | 30 / 1400ms | 탄띠 200 / 4000ms |

화력을 사는 대가로 기동성과 반응성을 전부 내준다. 일단 돌기 시작하면 가장 강하다.

**공회전 유예 0.6초**: 손을 떼도 총열이 계속 돌아 그 안에 다시 누르면 예열 없이 나간다.
끊어 쏘는 리듬이 생긴다. 총열 묶음 6개가 **분리된 SVG 그룹**이라 실제로 돌아가는 게 보인다.
조준점 팔도 함께 회전한다.
보조(짧게): **고정 사격** — 예열 후 20발을 자동으로 쏘고 멈춘다. 그 동안 확산 절반.
서바이벌에서 연사 중 드론이 조준 반대로 초당 40px 밀린다. 자리를 잡고 쏘는 무기가 된다.

# D. 예능 무기 (8단계)

사용자: "예능 무기도 넣어줘 뿅망치나 물총 같은거"

밸런스 밴드에서 제외하되 별도 규칙을 둔다.
> 실효 화력이 중앙값의 **25~50%**, 그리고 각각 **피해가 아닌 고유 효과**를 하나씩 가져야 한다.
> 약하지만 쓸 이유가 있어야 한다.

| 무기 | 피해 | 고유 효과 |
|---|---|---|
| **뿅망치** | 8 | 맞은 요소가 찌그러졌다 튀어오른다. "뿅" 소리와 별 입자. 가장 빠르게 휘두른다 |
| **물총** | 3/틱 | **젖음** 8초. 처지고 글자가 번지고 색이 빠진다. **냉각 2.5배, 더 멀리 미끄러짐.** 불을 끈다 |
| **나팔** | 5 | 90도 원뿔 420px 를 민다. **적의 탄환 방향을 뒤집는다** — 유일하게 전투 효용이 분명하다 |
| **고무 치킨** | 12 | 20% 확률로 `bouncy` 부여. 가장 빠르고 가볍고 예측 불가 |

물총 → 냉각총 → 망치가 가장 센 연계가 된다. 피해가 거의 없지만 **다른 무기를 강하게 만드는
준비 도구**다.

# E. 무기 다양화 (9단계)

무기를 더 넣는 기준은 "피해량이 다른가"가 아니라 **"할 수 있는 일이 다른가"** 다.

| 무기 | 새 동사 |
|---|---|
| **샷건** | 펠릿 9발 원뿔. **밀집한 작은 요소를 한 번에.** 사거리 감쇠 최대. 한 발씩 장전 |
| **못총** | **고정.** 맞은 조각이 그 자리에 박힌다. 공중에서 멈추고 수명의 영향을 받지 않는다 |
| **냉각총** | **빙결.** 받는 피해 ×1.8, 조각 수 ×2.5, 적은 2초 정지. SPA 리렌더도 묶는다 |
| **중력탄** | **끌어모으기.** 조각과 적의 탄환을 빨아들인다. 직접 피해 0 |

냉각총이 특히 중요하다. 혼자 쓰면 가장 약하고 반드시 다른 무기와 같이 써야 한다.
**로드아웃 구성에 처음으로 조합이라는 개념이 생긴다.**

# F. 밸런스 조정 (9단계)

## F1. 문제

수치가 명세 여럿에 걸쳐 그때그때 정해졌고 서로 비교된 적이 없다. 누가 센지, 왜 센지, 어떤
대가를 치르는지가 어디에도 없다.

## F2. 기준 표적

| 표적 | 최대 체력 |
|---|---|
| 단어 조각 | 19 |
| 버튼 | 44 |
| 작은 카드 | 99 |
| 큰 카드 | 184 |
| 큰 섹션 | 253 |

## F3. 공통 통화

```
burstDPS  = 한 교전에서 쉬지 않고 낼 수 있는 초당 피해 (연소는 dotDPS 를 가산)
uptime    = 실제로 쏠 수 있는 시간의 비율 (재장전·과열·예열·쿨다운 포함)
handling  = moveSpeed × (1 − swapMs/2000) × (1 − min(0.35, 유효산포/120))
effective = burstDPS × uptime × handling
```

## F4. 범주별 밴드

| 범주 | 무기 | 밴드 |
|---|---|---|
| 실전 | 망치·권총·기관총·저격총·도끼·카타나·폭탄·로켓·화염방사기·레이저·미니건·샷건·못총·붕괴 | 중앙값 **±18%** |
| 특수 | 냉각총·중력탄·충격포·견인 광선·고무탄 | 제공 효용 환산 후 **40~90%** |
| 예능 | 뿅망치·물총·나팔·고무 치킨 | **25~50%** + 고유 효과 비어 있지 않을 것 |

붕괴는 쿨다운으로 제한되는 특수기이므로 밴드 검사에서 제외한다.

## F5. 역할 — 각 무기가 "1등인 한 가지"

하나도 겹치면 안 된다. 겹치면 둘 중 하나는 존재 이유가 없다.
망치는 중형 단일 효율, 권총은 즉응성, 기관총은 중거리 균형, 저격총은 단발 최대와 무감쇠,
도끼는 근접 최대 피해, 카타나는 치명타율과 기동성, 폭탄은 범위당 효율, 로켓은 단발 범위 최대,
화염방사기는 누적 화력 최대, 레이저는 관통과 절단선 자유도, 미니건은 지속 화력 최대,
샷건은 밀집 다수 동시, 못총은 조각 고정, 냉각총은 피해 증폭, 중력탄은 끌어모으기,
붕괴는 광역 전멸.

## F6. `tools/balance.js`

밸런스를 문서가 아니라 **실행 가능한 검사**로 만든다.

- `src/` 의 무기 표를 정적 파싱해 표적 5종 × 무기별 처치 시간과 실효 화력을 표로 낸다.
- `--check` 가 다음을 위반하면 exit 1:
  1. 실효 화력이 범주 밴드를 벗어난다
  2. 같은 범주 안에서 다른 무기에 **완전히 지배**된다(모든 축에서 같거나 나쁨)
  3. 큰 카드(184)를 1회 타격으로 파괴한다(붕괴·충전 로켓·슬러그 제외)
  4. 큰 섹션(253)의 지속 사격 처치 시간이 4.5초를 넘는다
  5. `moveSpeed` 가 0.5 미만 또는 1.25 초과
- CI 가 돌린다. **밸런스 회귀가 테스트로 잡힌다.**
- 사람이 읽을 표는 `docs/BALANCE.md` 로 생성해 커밋한다.

## F7. 조정 절차

현재 수치 그대로 한 번 돌려 실태를 본 뒤, 역할표와 어긋나는 무기를 찾아 고친다.
**피해량보다 핸들링(교체·이동·산포·재장전)을 먼저 건드린다.** 피해량은 체감으로 기억하는
값이라 자주 바꾸면 혼란스럽다. 변경한 수치는 이유와 함께 `docs/BALANCE.md` 에 남긴다.

## F8. 모드별 보정

- `survival`: `handling` 의 `moveSpeed` 지수를 1.5 로 올려 검사한다. 이동이 생존에 직결된다.
- `arcade`: 한 손 조작이므로 반응 속도가 중요하다. `swapMs + 첫 발까지의 시간`을 따로 표에 넣는다.
- `rampage`: `moveSpeed` 항을 1 로 둔다.
