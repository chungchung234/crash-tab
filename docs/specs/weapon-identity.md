# 무기 개성 · 명중률 교정

사용자: **"무기의 중복도 너무 많아 단순히 무기가 겹친다기보단 액션이 너무 똑같고 재미도 없어
덜 겹치고 개성있게 해주고 기관총 류는 명중률 높여줘 너무 안맞아서 재미가 없어"**

---

# A. 진단 (측정값)

## A1. 액션이 두 템플릿으로 수렴했다

22종의 `fire` 본문을 분류했다. **12종이 템플릿 둘을 공유한다.**

| 템플릿 | 무기 | 본문 |
|---|---|---|
| 조준 → 산포 → 단일 피해 | smg · laser · minigun · rubber · shotgun · nailgun · freezegun | 20~31줄 |
| 조준 → 단일 피해 | hammer · axe · katana · squeaky · chicken | 12~17줄 |

차이는 **숫자와 덧붙은 부작용뿐**이다. 고무탄은 `bouncy` 를, 냉각총은 `frozen` 을,
못총은 고정을 끝에 한 줄로 더한다. 누르는 손끝에서 느껴지는 것은 전부 같다.

## A2. 못 하는 일이 있는 무기가 없다

`docs/BALANCE.md` 의 처치 시간표: **실전 14종 전부가 모든 표적을 1.4초 안에 지운다**
(카타나 2.08초만 예외). 표의 절반이 "즉시"다.

9단계가 실효 화력을 중앙값 ±18% 로 묶었고, 그 결과가 이것이다. **밴드는 성능을 같게 만들라는
뜻이지 역할을 같게 만들라는 뜻이 아니었는데**, 역할표(§F5)가 산문일 뿐 강제되지 않아
수치만 수렴했다. 선택에 의미가 없으면 액션이 아무리 달라도 같게 느껴진다.

## A3. 명중률은 거꾸로 되어 있다

`shotPoint` 는 `gauss(s)` 로 x·y 에 각각 **표준편차 s px** 을 더한다.
`s = spread + 반동킥 + 블룸`, 블룸 상한은 `bloom × 10`.

지속 사격이 상한에 닿았을 때의 실제 명중 확률(2차원 가우시안):

| 무기 | σ 상한 | 버튼 120×44 | 카드 300×200 | 문단 600×80 |
|---|---:|---:|---:|---:|
| `minigun` | 140px | **4%** | 38% | 22% |
| `smg` | 60px | **20%** | 89% | 50% |
| `laser` | 50px | 26% | 95% | 58% |
| `shotgun` | 40px | 36% | 99% | 68% |
| `flame` | 30px | 51% | 100% | 82% |
| `nailgun` | 20px | 73% | 100% | 95% |

미니건은 `bloom: 14`, 틱 60ms 이므로 **0.6초 만에** 상한에 닿는다. 방아쇠를 당긴 지
0.6초 뒤부터 버튼을 4% 로 맞힌다. 역할표는 미니건을 "지속 화력 최대"라고 적어 뒀다.

## A4. 왜 이렇게 됐나 — 검사가 못 맞는 것을 벌하지 않는다

```
handling = moveSpeed × (1 − swapMs/2000) × (1 − min(0.35, 유효산포/120))
burstDPS = hit × 1000 / interval          // 모든 탄이 맞는다고 가정
```

- 산포 항이 **유효산포 42px 에서 포화**한다. 그 위로는 더 부정확해져도 점수가 안 내려간다.
  미니건의 유효산포는 70px 이라 이미 포화 상태다. 블룸을 두 배로 올려도 점수는 그대로다.
- `burstDPS` 에 명중 확률이 없다. 못 맞는 무기가 서류상 1등이 된다.

**무기를 못 맞게 만드는 것이 밴드를 맞추는 공짜 손잡이였다.** 고치지 않으면 다음 조정에서
같은 일이 반복된다.

# B. 명중률 교정

## B1. 모델부터 고친다

```
pHit(W, 표적)  = erf((w/2)/(σ√2)) × erf((h/2)/(σ√2))      // σ = 유효산포
burstDPS      = hit × 1000 / interval × pHit(W, 버튼 120×44)
handling      = moveSpeed × (1 − swapMs/2000)             // 산포 항은 삭제
```

산포는 이제 **화력에** 들어간다. 핸들링에서 빼는 이유: 한 축을 두 번 세면 포화 상한이
필요해지고, 그 상한이 이 구멍을 만들었다. 기준 표적을 버튼(120×44)으로 고정한다 —
가장 작고 가장 자주 겨누는 것이다.

`tools/balance.js --check` 에 규칙을 하나 더한다:

> **§F6-6**: 실전 무기의 `pHit(버튼)` 이 **0.55 미만이면 실패**한다.
> 지속 사격 무기가 작은 표적을 절반도 못 맞히면 그것은 역할이 아니라 결함이다.

## B2. 수치

목표: 지속 사격 중에도 버튼을 **70% 이상** 맞힌다(σ ≤ 20px). 미니건만 예외로 65%.

| 무기 | bloom 전 → 후 | σ 상한 | 버튼 명중률 |
|---|---|---:|---:|
| `minigun` | 14 → **2.5** | 25px | 65% |
| `smg` | 6 → **2** | 20px | 73% |
| `laser` | 5 → **1.5** | 15px | 85% |
| `shotgun` | 4 → **3** | 30px | 51% ※ |
| `flame` | 3 → **2** | 20px | 73% |
| `nailgun` | 2 → **1.5** | 15px | 85% |
| `freezegun` | 5 → **2** | 20px | 73% |

※ 샷건은 펠릿 9발이 각자 판정하므로 **한 발이라도 맞을 확률**이 기준이다:
`1 − (1 − 0.51)^9 ≈ 99.8%`. 산포가 정체성인 유일한 무기이므로 남긴다.
§F6-6 검사는 샷건을 펠릿 보정한 값으로 본다.

**블룸 회복도 손본다.** 지금은 0.4초 정지 후 40px/s 다. 미니건이 상한에서 완전 회복하는 데
3.5초가 걸린다. 회복을 **120px/s** 로 올린다 — 손을 떼면 1초 안에 돌아온다.
"참다가 쏜다"가 성립해야 산포가 벌이 아니라 운용이 된다.

## B3. 피해 재조정은 하지 않는다

명중률이 오르면 실효 화력이 오른다. **그래도 피해값은 건드리지 않는다**(§F7 원칙).
모델이 이제 명중률을 보므로 밴드 이탈은 `--check` 가 잡는다. 벗어나면 **틱 간격과 탄창으로**
되돌린다. 피해값은 체감으로 기억하는 값이다.

# C. 개성 — 모든 무기는 **못 하는 일**이 있어야 한다

## C1. 원칙

> 무기의 정체성은 "무엇을 잘하는가"가 아니라 **"무엇을 못하는가"** 다.
> 못하는 것이 없으면 잘하는 것도 느껴지지 않는다.

§F5 역할표는 산문이라 강제되지 않았다. **표적 등급별 계수**로 바꿔 수치로 만든다.

## C2. 표적 등급

기존 기준 표적 5종을 **네 등급**으로 묶는다.

| 등급 | 예 | 면적 |
|---|---|---|
| 낱말 | 단어 조각 | < 3,000 |
| 작은 것 | 버튼 · 링크 · 입력 | 3,000 ~ 20,000 |
| 중간 | 카드 · 이미지 | 20,000 ~ 150,000 |
| 큰 것 | 섹션 · 큰 컨테이너 | > 150,000 |

## C3. 등급 계수 — 무기마다 **1.0 미만이 최소 하나**

`WEAPONS[id].vs = { word, small, mid, large }`. 피해에 곱한다. 기본 1.0.

| 무기 | 낱말 | 작은 것 | 중간 | 큰 것 | 읽는 법 |
|---|---:|---:|---:|---:|---|
| `hammer` | 1.0 | 1.0 | 1.0 | **0.5** | 큰 것은 망치로 안 된다 |
| `pistol` | 1.0 | **1.3** | 1.0 | **0.6** | 작은 것 저격 |
| `smg` | 1.0 | 1.0 | 1.0 | **0.7** | 무난하되 큰 것엔 약하다 |
| `sniper` | **0.4** | 1.0 | **1.4** | 1.2 | 낱말에 200을 쓰는 건 낭비다 |
| `axe` | **0.6** | 1.0 | **1.3** | 1.0 | 쪼갠다 |
| `katana` | **1.5** | 1.2 | **0.7** | **0.5** | 낱말과 작은 것을 썬다 |
| `bomb` | 1.0 | 1.0 | **1.2** | 1.0 | 뭉친 것 |
| `rocket` | **0.5** | **0.7** | 1.2 | **1.5** | 큰 것 전문 |
| `flame` | **1.4** | 1.1 | 1.0 | **0.6** | 번진다 |
| `laser` | 1.0 | 1.1 | 1.0 | **0.8** | 관통이 값이다 |
| `minigun` | **0.7** | **0.8** | 1.2 | **1.4** | 큰 것을 갈아낸다 |
| `shotgun` | 1.2 | **1.4** | **0.6** | **0.4** | 밀집한 작은 것 |
| `nailgun` | 1.0 | 1.2 | 1.0 | **0.7** | 고정이 값이다 |

**검사**: `tools/balance.js --check` 에 §F6-7 을 더한다.

> 실전 무기는 `vs` 에 **1.0 미만인 등급이 최소 하나** 있어야 한다.
> 그리고 **어떤 두 무기도 `vs` 네 값이 모두 같아서는 안 된다.**

이 둘이 "못 하는 일이 없다"와 "둘이 같다"를 **구조적으로** 막는다.

## C4. 액션 — 템플릿 둘을 쪼갠다

등급 계수만으로는 숫자가 달라질 뿐 손끝 느낌이 같다. 7종이 공유하는 템플릿을 **네 개의
서로 다른 동사**로 가른다. 전부 기존 시스템(변위·연소·관통·고정) 위에 올린다.

| 무기 | 지금 | 바꾼 뒤 |
|---|---|---|
| `smg` | 단일 피해 | **연사 누적**: 같은 요소를 연속으로 맞히면 탄마다 +8% (5발까지, 표적을 바꾸면 초기화). 집중 사격이 보인다 |
| `minigun` | 단일 피해 | **갈아내기**: 명중 시 그 요소의 **max 를** 0.6%씩 깎는다(최대 30%). 큰 것을 오래 갈면 작아진다 |
| `laser` | 단일 피해 | **지속 절단**: 같은 지점을 0.4초 유지하면 그 선을 따라 **분리**한다(6단계 절단선 재사용). 멈추면 처음부터 |
| `shotgun` | 단일 피해 | **펠릿 산개**: 이미 9발이지만 **각 펠릿이 서로 다른 요소를 찾는다**. 한 발로 군집을 쓸어낸다 |
| `nailgun` | 단일 피해 + 고정 | **못 박기**: 같은 요소에 못 3개를 박으면 **이웃 요소와 꿰맨다** — 둘이 같이 부서진다 |
| `freezegun` | 단일 피해 + 빙결 | **서리 전파**: 빙결된 요소에 맞히면 **맞닿은 이웃으로 빙결이 번진다**(불의 확산 재사용) |
| `rubber` | 단일 피해 + bouncy | **도탄**: 맞은 지점에서 가장 가까운 다른 요소로 **한 번 튕긴다**(피해 60%) |

근접 5종도 가른다.

| 무기 | 바꾼 뒤 |
|---|---|
| `hammer` | **내리찍기 파동**: 명중 지점에서 바깥으로 80px 충격파. 이웃이 흔들린다(변위, 피해 없음) |
| `axe` | **쪼개기**: 명중한 요소를 **항상 2조각**으로 가른다(6단계 분해 재사용). 피해가 아니라 분해가 값 |
| `katana` | 그대로 (곡선 베기가 이미 고유하다) |
| `squeaky` | **튕겨내기**: 피해 8 + 맞은 요소가 **반대로 날아간다**(변위 강함). 밀어내기 장난감 |
| `chicken` | 그대로 (20% 확률 bouncy 가 이미 고유하다) |

## C5. 하지 않는 것

- **무기를 더 넣지 않는다.** 23종이면 충분하다. 문제는 수가 아니라 구별이다.
- **피해값을 바꾸지 않는다.** §A2 가 못박은 아홉 개는 그대로다.
- **밴드를 느슨하게 하지 않는다.** 성능은 같아도 된다. 역할이 달라야 한다.

# D. 테스트

**명중률**: 각 무기의 `pHit(버튼)` 이 §B2 표와 ±3%p. 미니건이 0.6초 지속 사격 뒤에도
버튼을 60% 이상 맞힌다. 손을 떼고 1초 뒤 블룸이 0 이다. `--check` 가 §F6-6 을 잡는다
(일부러 bloom 을 14 로 되돌리면 exit 1).

**등급 계수**: 네 등급 표적에 각 무기를 쏴 피해가 `기본 × vs[등급]` 과 일치한다.
`--check` 가 §F6-7 을 잡는다(계수가 전부 1.0 인 무기를 넣으면 exit 1, 두 무기의 `vs` 를
같게 만들면 exit 1).

**액션**: §C4 의 일곱 + 넷이 각자 관측 가능한 고유 효과를 낸다 — 연사 누적이 5발째
1.4배, 미니건이 max 를 깎고, 레이저가 0.4초 뒤 분리하고, 샷건 펠릿이 서로 다른 요소를
맞히고, 못 3개가 이웃을 꿰매고, 서리가 번지고, 고무탄이 튕기고, 망치가 이웃을 흔들고,
도끼가 항상 2조각, 뿅망치가 날린다.

**무흔적**: 새 상태(꿰맴·갈아냄·연사 누적)가 걸린 채 `Escape` → `[data-crs]` 0개,
페이지 요소 인라인 스타일 원래 값, `max` 가 원래 값으로.
