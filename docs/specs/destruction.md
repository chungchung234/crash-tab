# 무기별 파괴 효과 · 타격 지점 · 폭발 교정 · 연소

로드맵 6단계. 1단계(요소별 데칼·재질)와 4단계(조준점의 폭발 반경 원) 위에 올라간다.

---

# A. 누적 피해가 보이게 — 데칼

지금은 네 번 쏴도 흔들리기만 하고 자국이 남지 않는다. 1단계가 만든 요소별 데칼 캔버스에
**무기별 흔적**을 그린다.

| 무기 | 자국 |
|---|---|
| 망치 | 거미줄 균열, 반지름 `18 + 10×(dmg/65)`, 6~9 짧은 가지 + 옅은 흰 멍 |
| 권총 | 5px 어두운 구멍 + 1px 밝은 테두리 + 3~5 실금. 구멍이 쌓인다 |
| 기관총 | 3px 구멍이 뭉치고, 40px 안에 6개 이상이면 잇는 찢김선이 생긴다 |
| 저격총 | 9px 구멍 + 탄도 반대쪽 60~110px 파편 원뿔 + 4~7 긴 가지 |
| 도끼 | 스윙 각도를 따르는 2~3px 베인 자국 + 4~8 쪼개짐 눈금 |
| 카타나 | 베기 궤적을 따르는 **어두운 호**(§D). 밝은 선을 남기지 않는다 |
| 폭탄 | 그을음 + 검댕 흩뿌림(§C) |
| 로켓 | 폭탄의 1.6배 + 분출 줄기 |
| 화염방사기 | 전체가 점점 그을린다. `charLevel = 1 − hp/max` |
| 붕괴 | 없음(즉시 파괴) |

**재질이 자국 종류를 바꾼다**(1단계 §5). 유리 재질만 거미줄 균열을 쓰고, 종이는 찢어진 결,
패널은 각진 금, 플라스틱은 흰 응력 자국, 금속은 패임이 된다. 무기 자국이 그 위에 곱해진다.

# B. 무기별 분해 방식

`WEAPONS[id].destruction = { shape, separation, finish, particles, delayMs, vaporise }`

## B1. 모양

- `wedge`(망치·폭탄): 타격점에서 방사형 쐐기 4~6
- `strip`(기관총): 구멍이 몰린 선에 수직인 3~5 띠
- `half`(도끼·카타나·저격총): 선 하나를 따라 정확히 2조각
- `shard`(로켓): 불규칙한 6~8 파편
- `ash`(화염방사기): 큰 조각 없이 8~16px 잿조각 18~30개
- `slab`(붕괴): 수평으로 1~2 덩어리

## B2. 흩어지는 방식

- `radial`: 타격점에서 바깥으로(현행)
- `implode`(권총): 90ms 동안 마지막 탄흔 쪽으로 빨려들다 중력이 받는다
- `cleave`(도끼): 두 반쪽이 베인 자국 위쪽을 축으로 반대로 회전. 장작 쪼개지듯
- `slide`(카타나): `delayMs` 뒤 절단면을 따라 미끄러진 뒤 떨어진다
- `burst`(폭탄·로켓): 600~1100 px/s + 강한 회전
- `drop`(붕괴·잿조각): 수평 속도 거의 없이 안쪽으로 기울며 낙하

## B3. 마감과 입자

마감: `scorch`(폭탄) `brightness(.82) saturate(.75)`, `char`(화염) `brightness(.45) sepia(.65)`,
`ember`(로켓) char + 350ms 불꼬리, `none`.

입자(공용 풀, 전체 상한 60, 성능 모드 절반, 모션 축소 시 정적 1개):
`dust`(망치·도끼·붕괴), `smoke`(폭탄·로켓), `spark`(총기류), `ash`(화염).

## B4. 배정

| 무기 | 모양 | 분리 | 마감 | 입자 | 지연 | 소멸 |
|---|---|---|---|---|---|---|
| 망치 | wedge | radial | none | dust | 0 | 0 |
| 권총 | wedge | implode | none | spark | 0 | 0 |
| 기관총 | strip | radial | none | spark | 0 | 0 |
| 저격총 | half | radial | none | spark | 0 | 0 |
| 도끼 | half | cleave | none | dust | 60 | 0 |
| 카타나 | half | slide | none | none | 140 | 0 |
| 폭탄 | wedge | burst | scorch | smoke | 0 | 0.15 |
| 로켓 | shard | burst | ember | smoke | 0 | 0.30 |
| 화염방사기 | ash | drop | char | ash | 0 | 0.25 |
| 붕괴 | slab | drop | none | dust | 0 | 0 |

`vaporise` 는 그 비율의 조각을 착지시키지 않고 비행 중 400~700ms 에 걸쳐 사라지게 한다.
큰 폭발이 페이지를 잔해로 묻는 것을 막는다.

## B5. 타격 방향

`hit = { x, y, angle | null, segment | null }` 을 `breakElement` 와 데칼에 함께 넘긴다.
총기는 예광 원점에서 타격점으로, 도끼는 스윙 각도, 카타나는 베기 선분,
폭발은 중심에서 요소 중심으로, 망치·붕괴·화염은 `null`.

# C. 타격 지점에 따라 다르게 부서진다

사용자: "어디를 때리든 똑같이 부셔지는 게 아니라 맞은 곳에 따라 다르게"

## C1. 현재 상태

- `velocityFor` 는 타격점을 **이미 쓴다.** 조각의 비행 방향과 속도가 달라진다.
- `splitRect` 는 타격점을 받지만 **상자 가운데 50% 안으로 강제 보정**한다.
  모서리를 때려도 한가운데와 비슷하게 갈라진다.
- `gridSplit`(폭탄 n=6, 로켓 n=8)은 타격점 인자를 **아예 받지 않는다.**

방향은 반영되고 균열 패턴은 반영되지 않는다.

## C2. 타격 구역

정규 좌표 `u = ix/w`, `v = iy/h`, 변 띠 두께 `B = clamp(0.18, 12px/min(w,h), 0.35)`.

| 구역 | 조건 | 결과 |
|---|---|---|
| `corner` | `u` 와 `v` 가 둘 다 바깥 `B` | 삼각형 모서리만 떨어지고 나머지는 남는다 |
| `edge` | 하나만 바깥 `B` | 그 변을 따라 판이 떨어지고 나머지는 남는다 |
| `center` | 그 외 | 전체가 방사형으로 산산조각 |

짧은 변 40px 미만은 항상 `center`. 띠를 잡을 공간이 없다.

## C3. 부분 파괴

`corner` 와 `edge` 는 요소를 없애지 않는다.

- 요소마다 `remain` 폴리곤을 유지한다. 최초값은 박스 사각형.
- **타격 1회 = 반평면 절단 1회.** Sutherland–Hodgman 으로 클리핑하면 남는 쪽과 떨어지는 쪽이
  한 번에 나온다. 항상 유효한 폴리곤이 보장되고 20줄이면 된다.
- 남은 모양을 원본에 `clip-path: polygon(...)` 으로 건다. 기존 인라인 값과 우선순위를
  `visibility` 와 같은 방식으로 저장했다 복원한다.
- 깊이는 피해에 비례: `cutDepth = clamp(dmg/maxHp, 0.12, 0.45)`.
- **전체 파괴 전환**: `remain` 면적이 원본의 35% 미만, HP 0, 또는 `center` 타격.
- 상한: 요소당 반평면 절단 8회.
- 한계(README): `clip-path` 는 넘치는 자식도 자르고 `position: fixed` 자손의 기준을 바꾼다.

## C4. 중앙 타격도 타격점을 따른다

- `splitRect` 의 가운데 보정 클램프를 **제거**한다. 피벗은 실제 타격점이며 상자 안에 4px 여유만.
- `gridSplit` 에 타격점을 넘긴다. 격자선이 타격점 쪽으로 최대 셀 폭의 30% 당겨지고,
  타격점이 속한 셀과 인접 8셀은 한 번 더 2분할한다. **터진 자리가 가장 잘게 부서진다.**

## C5. 이음새를 따라 갈라지기

절단선을 긋기 전에 타격점 40px 이내의 **자식 요소 경계선**을 찾는다(자식 40개까지만 훑음).
후보가 있으면 각도를 그 변에 스냅한다(허용 25도). 카드 안 이미지 모서리를 치면 이미지 경계를
따라 갈라진다.

# D. 카타나 베기 연출

## D1. 왜 지금이 가짜로 보이는가

| 현재 | 문제 |
|---|---|
| 직선 선분 + 수직 눈금 | 칼은 곡선으로 지나간다. 눈금은 톱자국처럼 보인다 |
| 밝은 흰 선이 남는다 | 실제로는 번쩍인 뒤 **어두운 칼자국**이 남는다 |
| 베자마자 갈라진다 | 벤 직후엔 아무 일도 없다가 뒤늦게 미끄러져 분리되는 게 칼이다 |
| 일반적인 바람소리 | 금속이 공기를 가르는 소리와 접촉의 울림이 없다 |

## D2. 새 연출

- **곡선 궤적**: 드래그 경로의 시작·중간·끝 세 점으로 2차 베지어. 중간점을 수직 방향으로
  `len × 0.12` 밀어 호를 만든다. 판정은 이 곡선을 24px 간격으로 샘플링한다.
- **잔상 0~180ms**: 곡선을 따라가는 **초승달**. 가운데 18px, 양 끝 0으로 가늘어짐.
  수직 그라데이션 흰색 95% → 투명. 0~60ms 에 그려지고 60~180ms 에 사라진다. 눈금 제거.
- **칼자국 180ms 이후 영구**: 어두운 호 하나만. `rgba(18,20,26,.55)`, 1.2px, 끝은 0.4px.
  벤 요소의 데칼에 그린다.
- **뒤늦은 분리**: 0ms 아무 일 없음 → 140ms 두 조각이 접선 방향으로 미끄러짐(170~230 px/s),
  절단면에 1프레임 흰 테두리 → 220ms 중력. `splitRect` 의 직선 절단을 **곡선 절단**으로 확장한다
  (베지어를 10개 선분으로 근사해 폴리곤을 자른다).
- **소리 세 겹**: 발도음(금속 마찰 2k→6kHz 70ms) + 공기 가르는 소리(대역통과 1.2kHz 120ms)
  + **접촉 울림(실제로 베었을 때만**, 삼각파 2.6k+3.9kHz 140ms 감쇠).
  허공을 그으면 울림이 없다. 이 차이가 손맛을 만든다.

# E. 폭발 교정

사용자: "폭발 이팩트와 그 흔적들이 폭발과 괴리가 너무 커"

## E1. 진단

네 숫자가 서로 다르다.

| | 현재 값 |
|---|---|
| 실제 폭발 반경 | 폭탄 240 / 로켓 360 |
| 그을음 반지름 | **90 고정, 무기 무관** |
| 균열 길이 | 220~420 |
| 충격파 링 | 480 고정 |

화면을 가로지르는 거대한 거미줄만 보이고 그을음은 묻힌다. 플레이어는 폭발 범위를 짐작할 수 없다.

더 근본적으로 **자국의 종류가 틀렸다.** 거미줄 균열은 맞아서 깨진 자국이다. 폭발이 남기는 것은
그을음·검댕·분출 흔적·그을린 테두리다.

## E2. 모든 크기를 실제 반경에 묶는다

`R = weapon.radius`. 아래 값이 전부 `R` 의 비율이다. `drawCrack` 의 `'bomb'` 분기를 삭제하고
`blastMark(x, y, R, intensity)` 경로를 만든다.

## E3. 폭발 자국

그리는 순서가 레이어 순서다.

1. **그을음 중심** — 반지름 `0.42R` 의 **불규칙한 덩어리**. 24각형에 ±12% 지터.
   `rgba(18,12,8,.55)` → `0.75` 에서 `.18` → 가장자리 0. 완전한 원이면 폭발로 안 보인다.
2. **검댕 흩뿌림** — `0.42R`~`0.85R` 에 60~110개 점(1~3px). 밀도는 반지름에 반비례.
   이게 "바깥으로 날아갔다"를 만든다.
3. **분출 줄기** — 10~16개. `0.15R` 에서 `0.6R`~`1.0R` 까지. 뿌리 3px, 끝 0으로 가늘어지는
   **곧은 선**. 균열의 꺾이고 가지치는 폴리라인과 **반드시 달라야 한다.**
   줄기는 힘의 방향, 균열은 취성 파괴다.
4. **중심부 짧은 균열** — 5~8개만, 길이 상한 `0.25R`.
5. **열 테두리** — `0.42R` 에 2px `rgba(255,228,196,.18)`.

로켓은 `intensity 1.5` 에 `1.1R` 까지 닿는 긴 줄기 3~5개 추가.
화염방사기의 기존 그을음은 `blastMark(x, y, 24, 0.25)` 로 통일한다.

**1단계 모델에 따라** 이 자국은 영향받은 **각 요소의 데칼에 나눠 그린다.** 요소 사이 빈 공간에는
남지 않는다.

## E4. 순서가 있는 연출

| 시점 | 일 |
|---|---|
| 0ms | 흰 섬광(반지름 `0.5R`, 90ms), 흔들림 시작 |
| 0ms | **충격파 링이 0 에서 `R` 까지 260ms 에 걸쳐 퍼진다** |
| 0~60ms | 대상들이 차례로 부서진다 |
| 40ms | `blastMark` 를 그린다. 섬광이 걷히며 드러난다 |
| 60~500ms | 중심에서 연기가 피어오른다 |

핵심은 **링이 실제 반경까지 퍼지는 것**이다. 고정 480px 링은 삭제하고 JS 가 `R` 로 크기를 준다.

## E5. 조준점과의 일관성

조준점의 점선 원 반지름 = 충격파 링 최종 반지름 = `WEAPONS[id].radius`.
세 곳이 같은 상수를 쓰는지 테스트로 고정한다. 쏘기 전 예고와 실제 결과가 맞아야 한다.

# F. 연소 시스템

사용자: "불 공격은 지속딜과 확산이 포인트인데 없네"

지금 화염방사기는 누르는 동안 틱 피해만 주고 떼면 끝난다. 불이 아니라 짧은 사거리의 지속 사격이다.

## F1. 상태

`state.burning: Map<Element, { stacks, lastTickAt, igniter, spreadAt }>`.
Map 을 쓰는 이유: 매 틱 전체를 순회해야 하므로 열거 가능해야 한다.

- `stacks` 0~100.
- **지속 피해** 초당 `2 + stacks × 0.14`. 100 스택이면 초당 16. 250ms 마다 1/4씩.
- **자연 감소** 초당 6. 100 스택은 약 16초간 타며 누적 150 전후를 준다.
  **불을 붙이고 떠나도 일이 진행된다.**
- 동시 연소 상한 20개(성능 모드 10).

## F2. 확산

연소 중인 요소는 700ms 마다 번질 곳을 찾는다. `stacks >= 45` 일 때만.

- 후보: rect 가 **24px 이내로 맞닿거나 겹치는** 다른 요소. 단순 거리가 아니라 **인접**이어야 한다.
  떨어진 곳으로 날아가면 불이 아니라 순간이동이다.
- 후보 탐색은 `walkCandidates` 의 300ms 캐시를 쓴다.
- 최대 2개까지 옮겨붙고 `stacks × 0.35` 를 받는다. 원래 쪽은 줄지 않는다. 불은 나눠 갖는 게
  아니라 번진다.
- 확산 시 두 요소 사이에 **불꽃이 튀는 연출**(입자 3개). 눈으로 번지는 게 보여야 한다.

밀집된 목록이나 카드 그리드에 붙이면 알아서 번진다. **페이지 구조가 그대로 가연성이 된다.**

## F3. 모습과 소리

- 아래 가장자리에 불꽃 오버레이(높이 `12 + stacks × 0.2`px, 0.12초 주기 흔들림).
  요소를 따라 움직인다.
- 그을림 데칼이 `stacks` 에 비례해 짙어진다. 연기가 피어오른다(요소당 초당 1.5개).
- 틴트 `filter: sepia(stacks/280) brightness(1 + stacks/900)`.
- 소리: 타닥거리는 저역 노이즈 루프 **하나**. 볼륨이 연소 요소 수에 비례한다.
  요소마다 소리를 내면 귀가 아프다. 확산 순간에 짧은 "화악".

## F4. 파괴·상태 연계

- 연소 중에 파괴된 요소는 **무엇에 맞아 죽었든** `ash` 조각 + `char` 마감으로 부서진다.
- 연소 중 요소가 폭발에 휘말리면 반경 ×1.15, 그 폭발이 주변에 스택 20을 뿌린다.
- **연소 중인 적대 요소는 복구를 하지 못한다.** 불로 묶어두는 전술이 생긴다.

| 상호작용 | 규칙 |
|---|---|
| 젖음 → 불 | 들어오는 스택 ×0.3. `stacks < 20` 에서 즉시 꺼짐 |
| 불 → 젖음 | `wet` 이 2배 속도로 마름 |
| 물총 → 불 | 틱당 스택 −40. 물총이 소화기가 된다 |
| 빙결 ↔ 불 | 서로 상쇄. 각각 초당 25씩 녹이고 끈다 |
| 완전 빙결 → 불 | 붙지 않는다. 먼저 녹여야 한다 |
| 변위 → 불 | 인접 판정이 현재 위치 기준이므로 **밀어서 떼면 방화선이 된다** |

## F5. 불을 붙이는 무기

화염방사기 틱당 9, 로켓 직격 25·범위 12, 폭탄 범위 15, 레이저 틱당 4, 그 외 0.

|---|---|---|

연료 12 소모, 쿨다운 1400ms. **확산의 시작점을 던져 놓는** 도구다.

# G. 테스트 요약

**데칼**: 첫 피해에 데칼 1개가 생기고 추가 타격에도 캔버스는 1개이며 비투명 픽셀이 늘어난다.
망치와 화염의 데칼이 평균 알파와 바운딩 박스로 구분된다. 파괴·복구·종료에 제거된다.

**분해**: 도끼 2조각, 카타나 2조각, 로켓 6~8, 화염 18~30개의 20px 미만 조각, 붕괴 1~2.
권총은 120ms 안에 조각의 평균 거리가 생성 시점보다 **작아진다**. 카타나는 `delayMs` 동안
움직이지 않다가 베기 각도 ±25도로 미끄러진다. 도끼 두 반쪽의 회전 부호가 반대다.
폭탄 조각에 `brightness` 필터가 있고 로켓은 `.crs-trail` 을 만들었다 1초 안에 치운다.

**타격 지점**: 같은 요소를 모서리와 한가운데에 때리면 조각 수와 `clip-path` 가 다르다.
모서리 타격은 `data-crs-broken` 없이 인라인 `clip-path` 가 걸리고 `stats().partial === 1`,
조각 면적이 원본의 45% 미만이다. 반복하면 `remain` 면적이 단조 감소하고 35% 미만에서 전체
파괴로 전환된다. 변 타격의 조각 바운딩 박스가 그 변에 2px 이내로 접한다.
폭발 격자에서 타격점 셀의 평균 조각 면적이 가장 먼 셀보다 작다.
이미지 왼쪽 경계 10px 이내를 치면 절단 각도가 그 경계와 25도 이내다.

**폭발**: 그을음 바깥 지름이 `0.85R` 과 ±8px. `0.25R` 를 넘는 균열 폴리라인이 없다.
링 최종 반지름이 `R` 과 ±6px 이고 폭탄과 로켓이 다르다.
**조준점 점선 원 = 링 최종 반지름 = `WEAPONS[id].radius`** 세 값이 같다.
발사 후 30ms 에 자국이 없고 80ms 에 있다. 폭발 자국과 망치 자국이 중심 알파와 외곽 폴리라인으로
구분된다.

**연소**: 100 스택에서 1초 뒤 체력이 16±3 줄고 손대지 않아도 계속 준다. 16초 안에 해제된다.
맞닿은 카드 3장 중 하나에 60 스택을 주면 2초 안에 나머지도 탄다. 40px 떨어진 카드에는 안 번진다.
젖은 요소는 스택이 30% 만 쌓이고 물총을 맞히면 줄어든다. 완전 빙결에는 안 붙는다.
타는 요소를 60px 밀어 인접을 끊으면 확산이 멈춘다. 연소 중 파괴되면 조각이 `ash` 다.
타는 적대 요소가 복구 빔을 쏘지 않는다. 화염탄 착탄점에 5초간 불바다가 남는다.
오디오 노드는 하나뿐이고 볼륨만 달라진다.

**무흔적**: 모든 상태가 걸린 채 `Escape` → `[data-crs]` 0개, 루프음 정지,
모든 요소의 `filter` 와 `clip-path` 복원.
