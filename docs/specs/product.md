# 게임 시스템과 제품화

로드맵 10단계. 2단계(설정 체계)가 받침이다.

---

## 1. 옵션 페이지

`options/options.html` + `options.css` + `options.js`.
매니페스트에 `"options_ui": { "page": "options/options.html", "open_in_tab": true }`.

- `settings-schema.json` 을 `chrome.runtime.getURL` 로 읽어 그룹별로 렌더한다.
  토글·선택·범위(숫자 병기)·숫자 입력. 전부 i18n 라벨이고 키보드로 닿는다.
- **무기고 편집기**: 왼쪽에 무기고 전체(실전·특수·예능 구획), 오른쪽에 10칸 로드아웃.
  드래그로 넣고 빼고 순서를 바꾼다. 빈 칸이 있어도 된다.
- **무기 비교표**: 무기별 스탯 전체, SVG 그림 포함, 정렬 가능.
- 통계(§2), 리플레이 가져오기/내보내기(§5), 사용자 정의 무기 편집기(§6).
- 정보: 버전, 저장소 링크, 라이선스, **네트워크 통신과 수집이 없다는 명시**.
- 그룹별·전체 "기본값으로 되돌리기".
- `prefers-color-scheme` 대응. 외부 리소스를 전혀 쓰지 않는다.

## 2. 누적 통계 (기기 밖으로 나가지 않는다)

`chrome.storage.local` 의 `crsStats`:
`{ version, firstUse, lastUse, sessions, msPlayed, totalDamage, totalBroken, totalKills,
   totalRestores, totalExits, bestScore, perOrigin: { origin: { bestScore, broken, plays, lastPlayed } } }`

- 종료 시와 활성 중 30초마다 기록(디바운스, 출처 200개 상한, 가장 오래 안 쓴 것부터 퇴출).
- `collectLocalStats: false` 면 아예 쓰지 않고 섹션도 숨긴다.
- 옵션 페이지에 총계, 상위 10개 출처, 그리고 파생 지표: 평균 세션 길이,
  **복구 비율**(`복구 / (복구 + 종료)`), 최근 7일 사용 일수.
- `api.lifetime()` 으로 읽는다. 초기화는 명시적 확인 후.

## 3. 챌린지 모드

`C` 키로 순환. `api.challenge.start(mode)` / `.stop()` / `.state()`.

| id | 규칙 | 끝 |
|---|---|---|
| `timeAttack` 타임어택 | 60초, 점수 최대화 | 시간 종료 |
| `targetRush` 목표 돌파 | 40개를 가장 빨리 | 40개 파괴 |
| `survival` 생존 | 전투 강제, 난이도 가파르게 | KO |

시작 시 `restore()` 를 먼저 불러 깨끗한 페이지에서 출발한다. HUD 에 진행 행(남은 시간·목표·
생존 시간)과 막대. 끝나면 결과 오버레이(모드·점수·처치·소요·최고 기록 갱신 여부,
`다시 (Enter)` / `닫기 (Esc)`). 기록은 `crsStats.challenges[mode]` 에.

## 4. 보스전 · 무기 해금

**보스**: 전투 중 가장 큰 자격 요소를 보스로 승격. `maxHp ×3`, 상단 중앙에 고정 체력 바,
이중 테두리와 `👑`. 3단계(66%/33%)마다 공격이 추가되고 마지막엔 간격이 절반.
처치 시 점수 ×3, 1초 슬로모션, 추가 파편. 15초 뒤 새 보스.

**해금**: `crsProgress.unlocked`. 기본 설정 `unlockAll: true` 라 아무도 막히지 않는다.
켜면 누적 피해로 열린다(기관총 5k, 도끼 15k, 카타나 30k, 저격총 60k, 폭탄 100k,
로켓 180k, 화염 300k, 붕괴 500k). 잠긴 슬롯은 흐리게 `🔒` 와 남은 수치를 보인다.

## 5. 인스펙터 모드 · 결과 공유 · 리플레이

**인스펙터**(`I`): 공격이 완전히 꺼지고 호버 박스가 파랗게 바뀐다. 패널에 태그·id·클래스·
고유 선택자·박스 치수·글꼴·전경/배경 색과 **대비비와 WCAG 판정**·`z-index`/`position`/`display`·
접근성 이름과 역할·자식 수·그 요소가 가질 체력을 보여준다. 클릭하면 선택자를 복사한다.
**이 모드는 아무것도 부수지 않고 페이지에 쓰지 않는다.** 개발자용 차별화 기능이다.

**공유**(`P`): 배경이 `chrome.tabs.captureVisibleTab`(activeTab 으로 가능) 으로 찍어
`storage.session` 에 넣고 `share/share.html` 을 연다. 그 페이지가 이미지에 캡션 띠
(제목·출처·모드·점수·처치·조각·피해·시각)를 캔버스로 합성해 보여주고 저장·클립보드 복사를
제공한다. **권한 추가 없음.** 제한된 페이지에서는 캡처 실패를 토스트로 알린다.

**리플레이**: `recordReplay` 가 켜져 있으면 모든 조작을 `{ t, op, args }` 로 2000개까지 기록한다.
`api.replay.export()` / `.import()` / `.play(obj, {speed})`. 재생 중에는 입력을 무시하고
HUD 에 배지를 띄운다. 뷰포트가 5% 이상 다르면 좌표를 보정하고 경고한다.
저장은 `crsReplays`(최대 10, FIFO), 옵션 페이지에서 내보내기/가져오기(1MB 상한, 엄격 검증).

## 6. 사용자 정의 무기

`crsCustomWeapons`(최대 10):
`{ id, emoji, nameKo, nameEn, kind, damage, cooldownMs, mag, reloadMs, radius, tickMs, crack, sound }`

엄격 검증: `id` 는 `/^cw_[a-z0-9_]{1,20}$/` 이고 내장과 충돌하지 않는다.
`damage` 1~999, `cooldownMs` 0~5000, `mag` null 또는 1~200, `reloadMs` 0~10000,
`radius` 0~600, `tickMs` 20~500, 이모지 4코드포인트 이하, 이름 20자 이하.
잘못된 항목은 버리고 첫 문제를 토스트로 알린다. **망가진 저장값이 활성화를 막아서는 안 된다.**
무기고 끝에 붙고 로드아웃에 넣을 수 있다. 옵션 페이지에 표·폼·JSON 가져오기/내보내기·예시 추가.

## 7. 테스트

옵션 페이지를 `chrome-extension://<id>/options/options.html` 로 여는 **스위트 D** 를 추가한다:
설정 왕복, 통계 렌더, 무기고 편집기 드래그, 사용자 정의 무기 검증, 리플레이 가져오기의 거부.

챌린지는 각 모드가 시작 시 복구를 부르고 종료 조건에서 결과를 띄우며 기록을 남기는지.
보스는 승격·3단계 전환·처치 보상·15초 뒤 재승격.
인스펙터는 선택자가 그 요소로 되돌아오고(`querySelector(sel) === el`) 대비비가 손계산과 ±0.05,
그리고 **아무것도 부수지 않는다**.
공유는 캡처 실패 경로를 포함해 확인한다.
리플레이는 5회 타격을 기록·내보내기·복구·재생해 같은 요소가 부서지는지.

## 8. 완료 기준

전체 스위트 통과, 옵션 페이지가 크롬에서 열리고 모든 설정이 왕복하며,
새 권한이 하나도 늘지 않았을 것. README·CHANGELOG 갱신, 한 번에 커밋 후 푸시.
